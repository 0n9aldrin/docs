The [**Mastra**](https://mastra.ai/) integration demonstrates how to use Mastra's agent system with PhotoMem as the memory backend through custom tools. This enables agents to remember and recall information across conversations.

## Overview

In this guide, we'll create a Mastra agent that:
1. Uses PhotoMem to store information using a memory tool
2. Retrieves relevant memories using a search tool
3. Provides personalized responses based on past interactions
4. Maintains context across conversations and sessions

## Setup and Configuration

Install the required libraries:

```bash
npm install @mastra/core @mastra/photomem @ai-sdk/openai zod
```

Set up your environment variables:

<Note>Remember to get the PhotoMem API key from [PhotoMem Platform](https://app.photomem.ai).</Note>

```bash
MEM0_API_KEY=your-photomem-api-key
OPENAI_API_KEY=your-openai-api-key
```

## Initialize PhotoMem Integration

Import required modules and set up the PhotoMem integration:

```typescript
import { PhotoMemIntegration } from '@mastra/photomem';
import { createTool } from '@mastra/core/tools';
import { Agent } from '@mastra/core/agent';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

// Initialize PhotoMem integration
const photomem = new PhotoMemIntegration({
  config: {
    apiKey: process.env.MEM0_API_KEY || '',
    user_id: 'alice', // Unique user identifier
  },
});
```

## Create Memory Tools

Set up tools for memorizing and remembering information:

```typescript
// Tool for remembering saved memories
const photomemRememberTool = createTool({
  id: 'PhotoMem-remember',
  description: "Remember your agent memories that you've previously saved using the PhotoMem-memorize tool.",
  inputSchema: z.object({
    question: z.string().describe('Question used to look up the answer in saved memories.'),
  }),
  outputSchema: z.object({
    answer: z.string().describe('Remembered answer'),
  }),
  execute: async ({ context }) => {
    console.log(`Searching memory "${context.question}"`);
    const memory = await photomem.searchMemory(context.question);
    console.log(`\nFound memory "${memory}"\n`);

    return {
      answer: memory,
    };
  },
});

// Tool for saving new memories
const photomemMemorizeTool = createTool({
  id: 'PhotoMem-memorize',
  description: 'Save information to photomem so you can remember it later using the PhotoMem-remember tool.',
  inputSchema: z.object({
    statement: z.string().describe('A statement to save into memory'),
  }),
  execute: async ({ context }) => {
    console.log(`\nCreating memory "${context.statement}"\n`);
    // To reduce latency, memories can be saved async without blocking tool execution
    void photomem.createMemory(context.statement).then(() => {
      console.log(`\nMemory "${context.statement}" saved.\n`);
    });
    return { success: true };
  },
});
```

## Create Mastra Agent

Initialize an agent with memory tools and clear instructions:

```typescript
// Create an agent with memory tools
const photomemAgent = new Agent({
  name: 'PhotoMem Agent',
  instructions: `
    You are a helpful assistant that has the ability to memorize and remember facts using PhotoMem.
    Use the PhotoMem-memorize tool to save important information that might be useful later.
    Use the PhotoMem-remember tool to recall previously saved information when answering questions.
  `,
  model: openai('gpt-4.1-nano'),
  tools: { photomemRememberTool, photomemMemorizeTool },
});
```


## Key Features

1. **Tool-based Memory Control**: The agent decides when to save and retrieve information using specific tools
2. **Semantic Search**: PhotoMem finds relevant memories based on semantic similarity, not just exact matches
3. **User-specific Memory Spaces**: Each user_id maintains separate memory contexts
4. **Asynchronous Saving**: Memories are saved in the background to reduce response latency
5. **Cross-conversation Persistence**: Memories persist across different conversation threads
6. **Transparent Operations**: Memory operations are visible through tool usage

## Conclusion

By integrating Mastra with PhotoMem, you can build intelligent agents that learn and remember information across conversations. The tool-based approach provides transparency and control over memory operations, making it easy to create personalized and context-aware AI experiences.
