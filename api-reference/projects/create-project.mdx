# POST /api/organizations/{orgId}/projects

| Method | Path | Auth | Rate Limit |
| --- | --- | --- | --- |
| POST | `/api/organizations/{orgId}/projects` | Bearer (Clerk JWT) | 50 req/min |

<Info>
  Projects provide isolated environments for different applications or use cases within your organization. Each project has its own API keys and memory storage.
</Info>

## Request

### Headers

| Name | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer CLERK_JWT_TOKEN` |
| `Content-Type` | Yes | `application/json` |

### Path Parameters

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `orgId` | string | Yes | Organization ID | `"org_abc123"` |

### Body

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `name` | string | Yes | Project name (3-50 characters) | `"Production API"` |
| `description` | string | No | Project description | `"Main production environment"` |

<CodeGroup>
```bash Shell
curl -X POST https://api.photomem.ai/api/organizations/org_abc123/projects \
  -H "Authorization: Bearer $CLERK_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Production API",
    "description": "Main production environment"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.photomem.ai/api/organizations/org_abc123/projects",
    headers={
        "Authorization": f"Bearer {CLERK_JWT_TOKEN}",
        "Content-Type": "application/json"
    },
    json={
        "name": "Production API",
        "description": "Main production environment"
    }
)
response.raise_for_status()
print(response.json())
```

```ts TypeScript
const response = await fetch(
  "https://api.photomem.ai/api/organizations/org_abc123/projects",

      Authorization: `Bearer ${CLERK_JWT_TOKEN}`,

```
</CodeGroup>

## Response

```json
{
  "project": {
    "id": "proj_xyz789",
    "name": "Production API",
    "slug": "production-api",
    "description": "Main production environment",
    "organization_id": "org_abc123",
    "created_at": "2024-01-15T10:30:00Z",
    "updated_at": "2024-01-15T10:30:00Z"
  }
}
```

| Status | Meaning | Fix |
| --- | --- | --- |
| `201` | Project created successfully | — |
| `400` | Invalid request body or project name already exists | Check request format and use unique name |
| `401` | Invalid or missing Clerk JWT | Verify JWT token from Clerk |
| `403` | Insufficient permissions | Requires MEMBER role or higher |
| `404` | Organization not found | Verify organization ID |
| `429` | Rate limit exceeded | Slow down requests |

<Tip>
  Project slugs are automatically generated from the project name and used for URLs and references.
</Tip>
