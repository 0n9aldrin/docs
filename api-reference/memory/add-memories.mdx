title: 'Add Memories'

## Overview

Add new memories by extracting information from conversation messages. PhotoMem automatically processes your messages, extracts meaningful facts, generates embeddings, and stores them for future retrieval.

<Info>
This endpoint processes messages through an LLM to extract discrete facts, ensuring each memory is atomic and searchable.
</Info>

## Request Body

<ParamField body="messages" type="array | string | object" required>
  Conversation messages to extract memories from. Can be a single string, message object, or array of messages.
  
  <Expandable title="Message Object">
    <ParamField body="role" type="string" required>
      Role of the message sender: `user`, `assistant`, or `system`
    </ParamField>
    
    <ParamField body="content" type="string" required>
      Content of the message
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="user_id" type="string">
  Unique identifier for the user. Use this to associate memories with end-users.
</ParamField>

<ParamField body="agent_id" type="string">
  Unique identifier for the agent. Use this to associate memories with specific AI agents.
</ParamField>

<ParamField body="run_id" type="string">
  Unique identifier for the conversation run or session.
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata to attach to the memories. Useful for filtering and organization.
</ParamField>

<ParamField body="tags" type="array">
  Array of string tags for categorizing memories.
</ParamField>

<ParamField body="memory_type" type="string" default="short_term">
  Type of memory: `short_term` or `long_term`
</ParamField>

<ParamField body="deduplicate" type="boolean" default="true">
  Whether to check for and skip duplicate memories based on content similarity.
</ParamField>

<Note>
You must provide at least one of `user_id`, `agent_id`, or `run_id` to associate the memory with an entity.
</Note>

## Response

<ResponseField name="memories" type="array">
  Array of extracted and stored memories.
  
  <Expandable title="Memory Object">
    <ResponseField name="id" type="string">
      Unique identifier for the memory
    </ResponseField>
    
    <ResponseField name="memory" type="string">
      The extracted memory content
    </ResponseField>
    
    <ResponseField name="event" type="string">
      Event type: `ADD`, `UPDATE`, or `DELETE`
    </ResponseField>
    
    <ResponseField name="hash" type="string">
      Content hash for deduplication
    </ResponseField>
    
    <ResponseField name="metadata" type="object">
      Metadata including user_id, agent_id, timestamps, tags, and custom fields
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="stats" type="object">
  Statistics about the memory extraction process.
  
  <Expandable title="Stats Object">
    <ResponseField name="extracted" type="integer">
      Number of memories extracted from the messages
    </ResponseField>
    
    <ResponseField name="duplicates_found" type="integer">
      Number of duplicate memories detected and skipped
    </ResponseField>
    
    <ResponseField name="entities_found" type="integer">
      Number of entities identified
    </ResponseField>
    
    <ResponseField name="relationships_created" type="integer">
      Number of relationships created between entities
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST 'https://api.photomem.ai/v1/memories' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "messages": [
      {
        "role": "user",
        "content": "My name is Sarah and I love playing tennis on weekends"
      }
    ],
    "user_id": "user_123",
    "tags": ["personal", "hobbies"]
  }'
```

```python Python
import requests

url = "https://api.photomem.ai/v1/memories"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "messages": [
        {
            "role": "user",
            "content": "My name is Sarah and I love playing tennis on weekends"
        }
    ],
    "user_id": "user_123",
    "tags": ["personal", "hobbies"]
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
```
