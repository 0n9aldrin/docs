## Quick Reference

### Memory Operations

| Method | Description | Python | TypeScript |
|--------|-------------|--------|------------|
| `add()` | Add new memories | ✅ | ✅ |
| `search()` | Search semantically | ✅ | ✅ |
| `get()` | Get by ID | ✅ | ✅ |
| `get_all()` / `getAll()` | List memories | ✅ | ✅ |
| `update()` | Update memory | ✅ | ✅ |
| `delete()` | Delete memory | ✅ | ✅ |
| `delete_all()` / `deleteAll()` | Bulk delete | ✅ | ✅ |
| `history()` | Get change history | ✅ | ✅ |

### Utility Methods

| Method | Description | Python | TypeScript |
|--------|-------------|--------|------------|
| `initialize()` | Setup connections | ✅ | ✅ |
| `close()` | Cleanup | ✅ | ✅ |
| `get_cache_stats()` / `getCacheStats()` | Cache metrics | ✅ | ✅ |

## Error Handling

All errors extend `PhotoMemError` with structured details:

```python
try:
    await memory.add("text", user_id=None)
except ValidationError as e:
    print(e.error_code)  # VALIDATION_ERROR
    print(e.message)     # Detailed error message
    print(e.suggestion)  # How to fix
    print(e.details)     # Additional context
```

## Type Safety

<Tabs>
  <Tab title="Python">
    All methods have complete type hints:

    ```python
    from typing import List, Optional, Union, Dict, Any
    from photomem.core.types import (
        MemoryResult,
        SearchResult,
        MemoryType,
        SearchFilters
    )

    async def add(
        self,
        messages: Union[str, Dict[str, str], List[Union[str, Dict[str, str]]]],
        user_id: Optional[str] = None,
        agent_id: Optional[str] = None,
        run_id: Optional[str] = None,
        metadata: Optional[Dict[str, Any]] = None,
        memory_type: MemoryType = MemoryType.SEMANTIC,
    ) -> MemoryResult:
        ...
    ```
  </Tab>

  <Tab title="TypeScript">
    Full TypeScript support with Zod validation:

    ```typescript
    import {
      MemoryResult,
      SearchResult,
      MemoryType,
      SearchOptions
    } from 'photomem';

    async add(
      messages: string | Message | Array<string | Message>,
      options: AddMemoryOptions = {}
    ): Promise<MemoryResult>

    async search(
      query: string,
      options: SearchOptions = {}
    ): Promise<SearchResult[]>
    ```
  </Tab>
</Tabs>

## Authentication

<Tabs>
  <Tab title="Library">
    Authentication happens via API keys in environment variables:

    ```bash
    export OPENAI_API_KEY="sk-..."
    export DATABASE_URL="postgresql://..."
    ```

    Or pass in configuration:

    ```python
    config = MemoryConfig(
        llm_api_key="sk-...",
        embedding_api_key="sk-...",
        vector_store_url="postgresql://..."
    )
    ```
  </Tab>

  <Tab title="REST API">
    Coming soon: Bearer token authentication

    ```bash
    curl -X POST https://api.photomem.ai/memories \
      -H "Authorization: Bearer YOUR_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{"messages": "I love pizza", "user_id": "phone:123"}'
    ```
  </Tab>
</Tabs>
