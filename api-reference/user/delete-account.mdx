---
title: 'Delete Account'
openapi: delete /api/users/me
---

Permanently delete the current user's account and all associated data.

<Warning>
This action is permanent and cannot be undone. All organizations, projects, memories, and API keys associated with this account will be permanently deleted.
</Warning>

## Authentication

This endpoint requires JWT authentication.

```bash
Authorization: Bearer YOUR_JWT_TOKEN
```

## What Gets Deleted

<Steps>
  <Step title="User Account">
    Your user profile and authentication credentials are permanently removed.
  </Step>
  
  <Step title="Organizations">
    All organizations you own are deleted (unless they have other owners).
  </Step>
  
  <Step title="Projects & Data">
    All projects, memories, and associated data are permanently deleted.
  </Step>
  
  <Step title="API Keys">
    All API keys are immediately revoked and cannot be used.
  </Step>
  
  <Step title="Billing">
    Active subscriptions are canceled immediately.
  </Step>
</Steps>

## Response

<ResponseField name="message" type="string">
  Confirmation message
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE https://api.photomem.ai/api/users/me \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

```typescript TypeScript
const response = await fetch('https://api.photomem.ai/api/users/me', {
  method: 'DELETE',
  headers: {
    'Authorization': `Bearer ${jwtToken}`
  }
});

const result = await response.json();
console.log(result.message);
```

```python Python
import requests

response = requests.delete(
    "https://api.photomem.ai/api/users/me",
    headers={"Authorization": f"Bearer {jwt_token}"}
)

result = response.json()
print(result["message"])
```
</RequestExample>

<ResponseExample>
```json Response
{
  "message": "Account deleted successfully"
}
```
</ResponseExample>

## GDPR Compliance

Account deletion is GDPR compliant:
- All personal data is permanently removed
- Data deletion is completed within 24 hours
- Audit logs are retained for compliance purposes only
- No data can be recovered after deletion

<Info>
If you need to export your data before deletion, use the [export API](/api-reference/usage/export-usage) first.
</Info>
