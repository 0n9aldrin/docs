# GET /api/organizations/{orgId}/projects/{projectId}/api-keys

| Method | Path | Auth | Rate Limit |
| --- | --- | --- | --- |
| GET | `/api/organizations/{orgId}/projects/{projectId}/api-keys` | Bearer (Clerk JWT) | 200 req/min |

<Info>
  List all API keys for a project, including their status, permissions, and usage information. Full key values are never returned - only prefixes for identification.
</Info>

## Request

### Headers

| Name | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer CLERK_JWT_TOKEN` |

### Path Parameters

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `orgId` | string | Yes | Organization ID | `"org_abc123"` |
| `projectId` | string | Yes | Project ID | `"proj_xyz789"` |

<CodeGroup>
```bash Shell
curl https://api.photomem.ai/api/organizations/org_abc123/projects/proj_xyz789/api-keys \
  -H "Authorization: Bearer $CLERK_JWT_TOKEN"
```

```python Python
import requests

response = requests.get(
    "https://api.photomem.ai/api/organizations/org_abc123/projects/proj_xyz789/api-keys",
    headers={"Authorization": f"Bearer {CLERK_JWT_TOKEN}"}
)
response.raise_for_status()
print(response.json())
```


| Status | Meaning | Fix |
| --- | --- | --- |
| `200` | API keys retrieved successfully | — |
| `401` | Invalid or missing Clerk JWT | Verify JWT token from Clerk |
| `403` | Insufficient permissions | Requires MEMBER role or higher |
| `404` | Organization or project not found | Verify IDs |
| `429` | Rate limit exceeded | Slow down requests |

<Note>
  The full API key is never returned for security. Use the `key_prefix` to identify keys.
</Note>
