## PhotoMem REST API

PhotoMem provides a comprehensive REST API for integrating advanced memory capabilities into your applications. Create, search, update, and manage memories across users, agents, and custom entities with simple HTTP requests.

<Info>
**Quick start:** Get your API key from the [PhotoMem Dashboard](https://app.photomem.ai/dashboard/api-keys) and make your first memory operation in minutes.
</Info>

---

## Quick Start Guide

Get started with PhotoMem API in three simple steps:

1. **[Add Memories](/api-reference/operations/add-memories)** - Store information and context from user conversations
2. **[Search Memories](/api-reference/operations/search-memories)** - Retrieve relevant memories using semantic search
3. **[Get Memories](/api-reference/operations/get-memories)** - Fetch all memories for a specific entity

## Authentication

All API requests require authentication using JWT-based authentication via Clerk. Include your JWT token in the Authorization header:

```bash
Authorization: Bearer <your-jwt-token>
```

Get your API key from the [PhotoMem Dashboard](https://app.photomem.ai/dashboard/api-keys).

<Warning>
**Keep your credentials secure.** Never expose API keys in client-side code or public repositories. Use environment variables and server-side requests only.
</Warning>
