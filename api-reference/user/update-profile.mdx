---
title: 'Update User Profile'
openapi: patch /api/users/me
---

Update the current user's profile information.

## Authentication

This endpoint requires JWT authentication.

```bash
Authorization: Bearer YOUR_JWT_TOKEN
```

## Request Body

<ParamField body="name" type="string">
  Updated full name
</ParamField>

<ParamField body="imageUrl" type="string">
  Updated profile image URL
</ParamField>

<Note>
Provide only the fields you want to update. Fields not included will remain unchanged.
</Note>

## Response

Returns the updated user profile with all fields.

<RequestExample>
```bash cURL
curl -X PATCH https://api.photomem.ai/api/users/me \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Alice M. Johnson"
  }'
```

```typescript TypeScript
const response = await fetch('https://api.photomem.ai/api/users/me', {
  method: 'PATCH',
  headers: {
    'Authorization': `Bearer ${jwtToken}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    name: 'Alice M. Johnson',
    imageUrl: 'https://avatars.example.com/alice-new.jpg'
  })
});

const updatedProfile = await response.json();
```

```python Python
import requests

response = requests.patch(
    "https://api.photomem.ai/api/users/me",
    headers={
        "Authorization": f"Bearer {jwt_token}",
        "Content-Type": "application/json"
    },
    json={
        "name": "Alice M. Johnson",
        "imageUrl": "https://avatars.example.com/alice-new.jpg"
    }
)

updated_profile = response.json()
```
