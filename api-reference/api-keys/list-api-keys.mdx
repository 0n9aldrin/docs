---
title: "List API Keys"
api: "GET /api/organizations/{org_id}/projects/{project_id}/api-keys"
description: "List all API keys for a project"
---

## Overview

Returns a list of all API keys for the specified project. Keys are returned with masked values (only the prefix is visible). Revoked keys are not included in the response.

## Authentication

Requires a valid Clerk session token. User must be a member of the organization.

## Path Parameters

<ParamField path="org_id" type="string" required>
  The unique identifier of the organization
</ParamField>

<ParamField path="project_id" type="string" required>
  The unique identifier of the project
</ParamField>

## Response

<ResponseField name="apiKeys" type="array">
  Array of API key objects

  <Expandable title="API Key Object">
    <ResponseField name="id" type="string">
      Unique identifier for the API key
    </ResponseField>

    <ResponseField name="name" type="string">
      Human-readable name for the API key
    </ResponseField>

    <ResponseField name="keyPrefix" type="string">
      First 12 characters of the key (e.g., "pm_live_abc1")
    </ResponseField>

    <ResponseField name="status" type="string">
      Status of the key: `active`, `expired`, or `revoked`
    </ResponseField>

    <ResponseField name="permissions" type="array">
      Array of permission strings (e.g., ["read", "write"])
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      ISO 8601 timestamp of when the key was created
    </ResponseField>

    <ResponseField name="lastUsedAt" type="string">
      ISO 8601 timestamp of when the key was last used (nullable)
    </ResponseField>

    <ResponseField name="expiresAt" type="string">
      ISO 8601 timestamp of when the key expires (nullable)
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.photomem.io/api/organizations/{org_id}/projects/{project_id}/api-keys" \
  -H "Authorization: Bearer YOUR_CLERK_TOKEN"
```

```python Python
import requests

response = requests.get(
    f"https://api.photomem.io/api/organizations/{org_id}/projects/{project_id}/api-keys",
    headers={"Authorization": f"Bearer {clerk_token}"}
)

api_keys = response.json()["apiKeys"]
for key in api_keys:
    print(f"{key['name']}: {key['keyPrefix']}... ({key['status']})")
```

```javascript JavaScript
const response = await fetch(
  `https://api.photomem.io/api/organizations/${orgId}/projects/${projectId}/api-keys`,
  {
    headers: {
      'Authorization': `Bearer ${clerkToken}`
    }
  }
);

const { apiKeys } = await response.json();
console.log(`Found ${apiKeys.length} API keys`);
```

</RequestExample>

## Notes

- Only active and expired keys are returned; revoked keys are filtered out
- The full API key value is never returned after creation
- Keys are ordered by creation date (newest first)
- Users only need to be members of the organization to view keys
