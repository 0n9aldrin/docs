---
title: "Create API Key"
api: "POST /api/organizations/{org_id}/projects/{project_id}/api-keys"
description: "Create a new API key for a project"
---

<Warning>
  **Important:** Save the full API key immediately. It will not be shown again after this response.
</Warning>

## Path Parameters

<ParamField path="org_id" type="string" required>
  The unique identifier of the organization
</ParamField>

<ParamField path="project_id" type="string" required>
  The unique identifier of the project
</ParamField>

## Request Body

<ParamField body="name" type="string" required>
  Human-readable name for the API key (minimum 3 characters)
</ParamField>

<ParamField body="permissions" type="array" default='["read", "write"]'>
  Array of permissions to grant
  
  **Available options:** `read`, `write`
</ParamField>

<ParamField body="expiresAt" type="string">
  Optional expiration date in ISO 8601 format. If not provided, key never expires.
</ParamField>

## Response

<ResponseField name="apiKey" type="object">
  <Expandable title="API Key Object">
    <ResponseField name="id" type="string">
      Unique identifier for the API key
    </ResponseField>

    <ResponseField name="name" type="string">
      Human-readable name for the API key
    </ResponseField>

    <ResponseField name="key" type="string">
      **Full API key value** - only shown once!
    </ResponseField>

    <ResponseField name="keyPrefix" type="string">
      First 12 characters of the key
    </ResponseField>

    <ResponseField name="status" type="string">
      Status of the key (always "active" for new keys)
    </ResponseField>

    <ResponseField name="permissions" type="array">
      Array of granted permissions
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      ISO 8601 timestamp of creation
    </ResponseField>

    <ResponseField name="expiresAt" type="string">
      ISO 8601 timestamp of expiration (nullable)
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://api.photomem.io/api/organizations/{org_id}/projects/{project_id}/api-keys" \
  -H "Authorization: Bearer YOUR_CLERK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Production API Key",
    "permissions": ["read", "write"],
    "expiresAt": null
  }'
```

```python Python
import requests

response = requests.post(
    f"https://api.photomem.io/api/organizations/{org_id}/projects/{project_id}/api-keys",
    headers={
        "Authorization": f"Bearer {clerk_token}",
        "Content-Type": "application/json"
    },
    json={
        "name": "Production API Key",
        "permissions": ["read", "write"],
        "expiresAt": None
    }
)

api_key = response.json()["apiKey"]
print(f"API Key created: {api_key['key']}")
print("⚠️  Save this key - it won't be shown again!")
```

```typescript TypeScript
const response = await fetch(
  `https://api.photomem.io/api/organizations/${orgId}/projects/${projectId}/api-keys`,
  {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${clerkToken}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      name: 'Production API Key',
      permissions: ['read', 'write'],
      expiresAt: null
    })
  }
);

const { apiKey } = await response.json();
console.log(`API Key: ${apiKey.key}`);
console.log('⚠️  Save this key - it won\'t be shown again!');
```
