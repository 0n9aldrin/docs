## Getting Started

Follow these steps to set up PhotoMem for local development.

<Steps>
<Step title="Clone the Repository">

```bash
git clone https://github.com/photomem/photomem.git
cd photomem
```
</Step>

<Step title="Set Up Environment">

Create a `.env` file in the project root:

```bash
# Required
OPENAI_API_KEY=sk-...
DATABASE_URL=postgresql://user:pass@localhost:5432/photomem

# Optional
EMBEDDING_CACHE_SIZE=1000
CONNECTION_POOL_SIZE=10
LOG_LEVEL=INFO
```
</Step>

<Step title="Start PostgreSQL">

Using Docker Compose (recommended):

```bash
cd python/server
docker-compose up -d
```

Or use your existing PostgreSQL with pgvector:

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```
</Step>

<Step title="Install Dependencies">

<Tabs>
  <Tab title="Python">
    ```bash
    cd python
    pip install -e ".[dev]"
    ```

    This installs PhotoMem in editable mode with development dependencies.
  </Tab>

  <Tab title="TypeScript">
    ```bash
    cd typescript
    npm install
    ```

    This installs all dependencies including dev tools.
  </Tab>
</Tabs>
</Step>
</Steps>

## Running Tests

<Tabs>
  <Tab title="Python">
    ```bash
    cd python

    # Run all tests
    pytest

    # Run with coverage
    pytest --cov=photomem --cov-report=html

    pytest tests/test_memory.py

    pytest -v
    ```

  </Tab>

  <Tab title="TypeScript">
    ```bash
    cd typescript

    # Run all tests
    npm test

    # Run with coverage
    npm run test:coverage

    # Run specific test
    npm test -- memory.test.ts

    # Watch mode
    npm run test:watch
    ```
  </Tab>
</Tabs>

## Running the Server

Start the REST API server for local testing:

```bash
cd python/server

# Using Docker
docker-compose up

# Or directly
uvicorn main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Database connection error">
    Ensure PostgreSQL is running and DATABASE_URL is correct:
    
    ```bash
    psql $DATABASE_URL -c "SELECT 1"
    ```

    Common issues:
    - PostgreSQL not running
    - Wrong credentials
    - Missing database
    - Firewall blocking connection
  </Accordion>

  <Accordion title="Import errors">
    Make sure you installed the package in development mode:
    
    ```bash
    # Python
    pip install -e ".[dev]"

    # TypeScript
    npm install
    ```

    Also check your Python/Node version matches requirements.
  </Accordion>

  <Accordion title="Test failures">
    Run tests with verbose output to see details:
    
    ```bash
    # Python
    pytest -v --tb=short

    # TypeScript
    npm test -- --verbose
    ```

    Common issues:
    - Missing environment variables
    - Database not initialized
    - Port conflicts
  </Accordion>

  <Accordion title="pgvector extension missing">
    Install the pgvector extension:
    
    ```bash
    # Ubuntu/Debian
    sudo apt-get install postgresql-15-pgvector

    # macOS with Homebrew
    brew install pgvector

    # Then enable in your database
    psql $DATABASE_URL -c "CREATE EXTENSION IF NOT EXISTS vector"
    ```
  </Accordion>

  <Accordion title="OpenAI API errors">
    Verify your API key:
    
    ```bash
    # Test the key
    curl https://api.openai.com/v1/models \
      -H "Authorization: Bearer $OPENAI_API_KEY"
    ```

    Make sure the key:
    - Is valid and not expired
    - Has sufficient credits
    - Has correct permissions
  </Accordion>
</AccordionGroup>

## Development Workflow

1. **Create a branch** for your feature:
   ```bash
   git checkout -b feature/my-feature
   ```

2. **Make changes** and test locally:
   ```bash
   pytest  # or npm test
   ```

3. **Format and lint**:
   ```bash
   black . && ruff check .  # Python
   npm run format && npm run lint  # TypeScript
   ```

4. **Commit changes**:
   ```bash
   git add .
   git commit -m "feat: add my feature"
   ```

5. **Push and create PR**:
   ```bash
   git push origin feature/my-feature
   ```
