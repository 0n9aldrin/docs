## Welcome to PhotoMem API

The PhotoMem API provides a simple REST interface for storing, searching, and managing memories for your AI applications.

## Base URL

All API requests should be made to:

```
https://api.photomem.ai
```

## Authentication

All API requests require authentication using an API key in the Authorization header:

```bash
Authorization: Bearer YOUR_API_KEY
```

<Warning>
  Never expose your API key in client-side code. Always make API calls from your
  backend server.
</Warning>

## Response Format

All API responses return JSON with the following structure:

<ResponseExample>
```json Success Response
{
  "success": true,
  "data": {
    // Response data here
  }
}
```

```json Error Response
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable error message"
  }
}
```

</ResponseExample>
