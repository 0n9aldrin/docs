## LangChain Integration

Add persistent memory capabilities to your LangChain applications with PhotoMem.

<Info>
This integration guide is coming soon! Check back for updates or [join our Discord](https://discord.gg/photomem) for early access.
</Info>

## Quick Example

```python
from langchain.memory import PhotoMemMemory
from photomem import PhotoMem

# Initialize PhotoMem
client = PhotoMem(api_key="your-api-key")

# Use with LangChain
memory = PhotoMemMemory(client=client)

# Your LangChain agent with PhotoMem memory
```
