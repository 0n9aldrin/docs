# DELETE /v1/memories/{memory_id}

| Method | Path | Auth | Rate Limit |
| --- | --- | --- | --- |
| DELETE | `/v1/memories/{memory_id}` | Bearer (API Key) | 100 req/min |

<Warning>
  This operation is irreversible. Deleted memories cannot be recovered. Consider exporting important data before deletion.
</Warning>

<Info>
  Use this endpoint to permanently remove a specific memory from your system.
</Info>

## Request

### Headers

| Name | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer YOUR_API_KEY` |

### Path Parameters

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `memory_id` | string | Yes | Unique identifier of the memory to delete | `"mem_abc123"` |

<CodeGroup>
```bash Shell
curl -X DELETE https://api.photomem.ai/v1/memories/mem_abc123 \
  -H "Authorization: Bearer $PHOTOMEM_API_KEY"
```

```python Python
import requests

response = requests.delete(
    "https://api.photomem.ai/v1/memories/mem_abc123",
    headers={"Authorization": f"Bearer {API_KEY}"}
)
response.raise_for_status()
```

```ts TypeScript
const response = await fetch(
  "https://api.photomem.ai/v1/memories/mem_abc123",
  {
    method: "DELETE",
    headers: {
      Authorization: `Bearer ${process.env.PHOTOMEM_API_KEY}`,
    },
  }
);
```
</CodeGroup>

## Response

```
204 No Content
```

| Status | Meaning | Fix |
| --- | --- | --- |
| `204` | Memory deleted successfully | — |
| `401` | Invalid or missing API key | Check your API key in dashboard |
| `404` | Memory not found | Verify memory_id exists |
| `429` | Rate limit exceeded | Slow down requests or upgrade plan |

<Note>
  A successful deletion returns `204 No Content` with an empty response body.
</Note>

## Bulk Delete

To delete multiple memories at once, use the bulk delete endpoint:

```
DELETE /v1/memories?user_id={user_id}&confirm=true
```

<CodeGroup>
```bash Shell
curl -X DELETE "https://api.photomem.ai/v1/memories?user_id=user_123&confirm=true" \
  -H "Authorization: Bearer $PHOTOMEM_API_KEY"
```

```python Python
import requests

response = requests.delete(
    "https://api.photomem.ai/v1/memories",
    headers={"Authorization": f"Bearer {API_KEY}"},
    params={
        "user_id": "user_123",
        "confirm": True
    }
)
response.raise_for_status()
print(response.json())
```

```ts TypeScript
const params = new URLSearchParams({
  user_id: "user_123",
  confirm: "true"
});

const response = await fetch(
  `https://api.photomem.ai/v1/memories?${params}`,
  {
    method: "DELETE",
    headers: {
      Authorization: `Bearer ${process.env.PHOTOMEM_API_KEY}`,
    },
  }
);
```
</CodeGroup>

<Warning>
  Bulk delete requires the `confirm=true` parameter to prevent accidental deletions. All memories matching the filter will be permanently deleted.
</Warning>
