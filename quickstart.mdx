## Overview

This guide will help you make your first API call to PhotoMem and store your first memory.

<Steps>
<Step title="Get Your API Key">
  Sign up for PhotoMem and obtain your API key from the dashboard.

  <Warning>
  Keep your API key secure. Never expose it in client-side code or commit it to version control.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  Store your first memory using a simple POST request.

  <CodeGroup>
  ```bash cURL
  curl -X POST 'https://api.photomem.ai/v1/memories/' \
    -H 'Authorization: Bearer YOUR_API_KEY' \
    -H 'Content-Type: application/json' \
    -d '{
      "messages": [
        {
          "role": "user",
          "content": "My name is John and I love pizza"
        }
      ],
      "user_id": "user_123"
    }'
  ```

```python Python
import requests

url = "https://api.photomem.ai/v1/memories/"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "messages": [
        {
            "role": "user",
            "content": "My name is John and I love pizza"
        }
    ],
    "user_id": "user_123"
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.photomem.ai/v1/memories/", {
  method: "POST",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    messages: [
      {
        role: "user",
        content: "My name is John and I love pizza",
      },
    ],
    user_id: "user_123",
  }),
});

const data = await response.json();
console.log(data);
```

  </CodeGroup>

  <Check>
  You should receive a response with the stored memory details.
  </Check>
</Step>

<Step title="Search Memories">
  Retrieve relevant memories using semantic search.

  <CodeGroup>
  ```bash cURL
  curl -X POST 'https://api.photomem.ai/v1/memories/search/' \
    -H 'Authorization: Bearer YOUR_API_KEY' \
    -H 'Content-Type: application/json' \
    -d '{
      "query": "What food does the user like?",
      "user_id": "user_123"
    }'
  ```

```python Python
import requests

url = "https://api.photomem.ai/v1/memories/search/"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "query": "What food does the user like?",
    "user_id": "user_123"
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.photomem.ai/v1/memories/search/", {
  method: "POST",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    query: "What food does the user like?",
    user_id: "user_123",
  }),
});

const data = await response.json();
console.log(data);
```

  </CodeGroup>

  <Check>
  PhotoMem will return relevant memories matching your query.
  </Check>
</Step>
</Steps>
