# GET /v1/memories

| Method | Path | Auth | Rate Limit |
| --- | --- | --- | --- |
| GET | `/v1/memories` | Bearer (API Key) | 200 req/min |

<Info>
  Use this endpoint to list memories with optional filtering by user, agent, run, tags, or memory type. For complex filtering, use POST /v1/memories/query instead.
</Info>

## Request

### Headers

| Name | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer YOUR_API_KEY` |

### Query Parameters

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `user_id` | string | No | Filter by user ID | `"user_123"` |
| `agent_id` | string | No | Filter by agent ID | `"agent_456"` |
| `run_id` | string | No | Filter by run/session ID | `"run_789"` |
| `tags` | array | No | Filter by tags (comma-separated) | `"support,billing"` |
| `memory_type` | string | No | Filter by type: `short_term` or `long_term` | `"long_term"` |
| `limit` | integer | No | Max results to return (1-1000) | `100` |
| `offset` | integer | No | Number of results to skip for pagination | `0` |

<CodeGroup>
```bash Shell
curl "https://api.photomem.ai/v1/memories?user_id=user_123&limit=10" \
  -H "Authorization: Bearer $PHOTOMEM_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.photomem.ai/v1/memories",
    headers={"Authorization": f"Bearer {API_KEY}"},
    params={
        "user_id": "user_123",
        "limit": 10
    }
)
response.raise_for_status()
print(response.json())
```

```ts TypeScript
const params = new URLSearchParams({
  user_id: "user_123",
  limit: "10"
});

const response = await fetch(
  `https://api.photomem.ai/v1/memories?${params}`,
  {
    headers: {
      Authorization: `Bearer ${process.env.PHOTOMEM_API_KEY}`,
    },
  }
);

const data = await response.json();
console.log(data);
```
</CodeGroup>

<Tip>
  Use pagination with `limit` and `offset` to efficiently retrieve large result sets.
</Tip>

| Status | Meaning | Fix |
| --- | --- | --- |
| `200` | Memories retrieved successfully | — |
| `400` | Invalid parameter format | Check parameter values and types |
| `401` | Invalid or missing API key | Check your API key in dashboard |
| `429` | Rate limit exceeded | Slow down requests or upgrade plan |

<Note>
  Returns an empty array `[]` if no memories match the filter criteria.
