# GET /api/organizations

| Method | Path | Auth | Rate Limit |
| --- | --- | --- | --- |
| GET | `/api/organizations` | Bearer (Clerk JWT) | 200 req/min |

<Info>
  Use this endpoint to list all organizations the authenticated user belongs to, including their role and organization details.
</Info>

## Request

### Headers

| Name | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer CLERK_JWT_TOKEN` |

<CodeGroup>
```bash Shell
curl https://api.photomem.ai/api/organizations \
  -H "Authorization: Bearer $CLERK_JWT_TOKEN"
```

```python Python
import requests

response = requests.get(
    "https://api.photomem.ai/api/organizations",
    headers={"Authorization": f"Bearer {CLERK_JWT_TOKEN}"}
)
response.raise_for_status()
print(response.json())
```

```ts TypeScript
const response = await fetch("https://api.photomem.ai/api/organizations", {
  headers: {
    Authorization: `Bearer ${CLERK_JWT_TOKEN}`,
  },
});

const data = await response.json();
console.log(data);
```
</CodeGroup>

## Response

```json
{
  "organizations": [
    {
      "id": "org_abc123",
      "name": "Acme Corp",
      "slug": "acme-corp",
      "role": "owner",
      "created_at": "2024-01-15T10:30:00Z",
      "member_count": 5,
      "project_count": 3
    }
  ]
}
```

| Status | Meaning | Fix |
| --- | --- | --- |
| `200` | Organizations retrieved successfully | — |
| `401` | Invalid or missing Clerk JWT | Verify JWT token from Clerk |
| `404` | User not found | Ensure user exists in system |
| `429` | Rate limit exceeded | Slow down requests |

<Note>
  Currently, users can belong to one organization. Future versions will support multiple organization memberships.
</Note>
