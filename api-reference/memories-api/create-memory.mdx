---
title: "Create Memory"
api: "POST /api/v1/memories"
description: "Create a new memory"
---

## Overview

Creates a new memory using API key authentication. Memories are automatically deduplicated based on content hash.

## Authentication

Requires API key in `Authorization` header: `Bearer YOUR_API_KEY`

## Request Body

<ParamField body="content" type="string" required>
  Memory content (max 10KB)
</ParamField>

<ParamField body="userId" type="string" required>
  User identifier for this memory
</ParamField>

<ParamField body="userName" type="string">
  Optional user display name
</ParamField>

<ParamField body="tags" type="array">
  Optional array of tags
</ParamField>

## Response

<ResponseField name="memory" type="object">
  <Expandable title="Memory Object">
    <ResponseField name="id" type="string">Memory identifier</ResponseField>
    <ResponseField name="userId" type="string">User ID</ResponseField>
    <ResponseField name="userName" type="string">User name</ResponseField>
    <ResponseField name="content" type="string">Memory content</ResponseField>
    <ResponseField name="tags" type="array">Tags array</ResponseField>
    <ResponseField name="createdAt" type="string">Creation timestamp</ResponseField>
    <ResponseField name="updatedAt" type="string">Last update timestamp</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://api.photomem.io/api/v1/memories" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "User prefers dark mode in all applications",
    "userId": "user_123",
    "userName": "John Doe",
    "tags": ["preference", "ui"]
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.photomem.io/api/v1/memories",
    headers={
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    },
    json={
        "content": "User prefers dark mode in all applications",
        "userId": "user_123",
        "userName": "John Doe",
        "tags": ["preference", "ui"]
    }
)

memory = response.json()["memory"]
print(f"Created memory: {memory['id']}")
```

```javascript JavaScript
const response = await fetch('https://api.photomem.io/api/v1/memories', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${apiKey}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    content: 'User prefers dark mode in all applications',
    userId: 'user_123',
    userName: 'John Doe',
    tags: ['preference', 'ui']
  })
});

const { memory } = await response.json();
console.log(`Created: ${memory.id}`);
```

## Content Guidelines

- Maximum size: 10KB per memory
- Automatic deduplication based on content hash
- Supports plain text and structured content
- Tags are case-insensitive and automatically normalized
