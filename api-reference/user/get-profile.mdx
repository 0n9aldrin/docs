---
title: "Get User Profile"
api: "GET /api/users/me"
description: "Get current user's profile information"
---

## Response

<ResponseField name="id" type="string">User identifier</ResponseField>
<ResponseField name="clerkId" type="string">Clerk user ID</ResponseField>
<ResponseField name="email" type="string">User email address</ResponseField>
<ResponseField name="fullName" type="string">User's full name</ResponseField>
<ResponseField name="organizationId" type="string">Organization ID (if member of one)</ResponseField>
<ResponseField name="role" type="string">
  Role in organization
  
  **Available options:** `owner`, `admin`, `member`
</ResponseField>
<ResponseField name="isActive" type="boolean">Whether account is active</ResponseField>
<ResponseField name="needsOnboarding" type="boolean">Whether user needs onboarding</ResponseField>
<ResponseField name="createdAt" type="string">Account creation timestamp</ResponseField>
<ResponseField name="updatedAt" type="string">Last update timestamp</ResponseField>
<ResponseField name="lastLoginAt" type="string">Last login timestamp</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.photomem.io/api/users/me" \
  -H "Authorization: Bearer YOUR_CLERK_TOKEN"
```

```python Python
import requests

response = requests.get(
    "https://api.photomem.io/api/users/me",
    headers={"Authorization": f"Bearer {clerk_token}"}
)

profile = response.json()
print(f"{profile['fullName']} ({profile['email']})")
print(f"Role: {profile['role']}")
```

```typescript TypeScript
const response = await fetch('https://api.photomem.io/api/users/me', {
  headers: {
    'Authorization': `Bearer ${clerkToken}`
  }
});

const profile = await response.json();
console.log(`${profile.fullName} (${profile.email})`);
console.log(`Role: ${profile.role}`);
```

</RequestExample>
