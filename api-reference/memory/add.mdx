## Overview

The Add Memories endpoint extracts and stores relevant information from conversation messages, creating persistent memories for your users.

## Request Body

<ParamField body="messages" type="array" required>
  Array of conversation messages to extract memories from.

  <Expandable title="Message Object">
    <ParamField body="role" type="string" required>
      Role of the message sender. Values: `user`, `assistant`, `system`
    </ParamField>

    <ParamField body="content" type="string" required>
      Content of the message
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="user_id" type="string" required>
  Unique identifier for the user. Used to associate memories with specific users.
</ParamField>

<ParamField body="metadata" type="object">
  Optional metadata to attach to the memories. Useful for filtering and categorization.
</ParamField>

## Response

<ResponseField name="memories" type="array">
  Array of extracted and stored memories.

  <Expandable title="Memory Object">
    <ResponseField name="id" type="string">
      Unique identifier for the memory
    </ResponseField>

    <ResponseField name="content" type="string">
      The extracted memory content
    </ResponseField>

    <ResponseField name="user_id" type="string">
      User ID associated with this memory
    </ResponseField>

    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the memory was created
    </ResponseField>

    <ResponseField name="metadata" type="object">
      Metadata attached to the memory
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST 'https://api.photomem.ai/v1/memories/' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "messages": [
      {
        "role": "user",
        "content": "My name is Sarah and I work as a software engineer in San Francisco"
      }
    ],
    "user_id": "user_123",
    "metadata": {
      "session_id": "session_456"
    }
  }'
```

```python Python
import requests

url = "https://api.photomem.ai/v1/memories/"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "messages": [
        {
            "role": "user",
            "content": "My name is Sarah and I work as a software engineer in San Francisco"
        }
    ],
    "user_id": "user_123",
    "metadata": {
        "session_id": "session_456"
    }
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
```

```javascript JavaScript
const response = await fetch('https://api.photomem.ai/v1/memories/', {
  method: 'POST',

    metadata: {
      session_id: 'session_456'
    }
  })
});

const data = await response.json();
console.log(data);
```
