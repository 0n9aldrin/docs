## API Key Authentication

PhotoMem uses API key authentication. Include your API key in the Authorization header of every request.

### Getting Your API Key

<Steps>
<Step title="Sign Up">
  Create an account at [app.photomem.ai](https://app.photomem.ai)
</Step>

<Step title="Generate API Key">
  Navigate to your dashboard and generate a new API key
</Step>

<Step title="Store Securely">
  Save your API key securely. You won't be able to see it again.

  <Warning>
  Never commit API keys to version control or expose them in client-side code.
  </Warning>
</Step>
</Steps>

## Making Authenticated Requests

Include your API key in the `Authorization` header using the Bearer scheme:

<CodeGroup>
```bash cURL
curl -X GET 'https://api.photomem.ai/v1/memories/' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

headers = {
    "Authorization": "Bearer YOUR_API_KEY"
}

response = requests.get(
    "https://api.photomem.ai/v1/memories/",
    headers=headers
)
```

```javascript JavaScript
const response = await fetch('https://api.photomem.ai/v1/memories/', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});
```
</CodeGroup>

## Best Practices

<AccordionGroup>
<Accordion title="Use Environment Variables">
  Store API keys in environment variables, never hardcode them:

  ```python
  import os

  API_KEY = os.getenv('PHOTOMEM_API_KEY')
  ```
</Accordion>

<Accordion title="Rotate Keys Regularly">
  Generate new API keys periodically and revoke old ones from your dashboard.
</Accordion>

<Accordion title="Use Different Keys for Different Environments">
  Create separate API keys for development, staging, and production environments.
</Accordion>
</AccordionGroup>

## Authentication Errors

<ResponseExample>
```json 401 Unauthorized
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid or missing API key"
  }
}
```

```json 403 Forbidden
{
  "error": {
    "code": "FORBIDDEN",
    "message": "API key does not have permission for this resource"
  }
}
```
</ResponseExample>

<Tip>
If you're getting authentication errors, verify that your API key is correct and hasn't been revoked.
</Tip>
