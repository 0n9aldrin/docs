# POST /v1/search

| Method | Path | Auth | Rate Limit |
| --- | --- | --- | --- |
| POST | `/v1/search` | Bearer (API Key) | 100 req/min |

<Info>
  Use semantic search to find relevant memories based on natural language queries. PhotoMem uses vector similarity to match meaning, not just keywords.
</Info>

## Request

### Headers

| Name | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer YOUR_API_KEY` |
| `Content-Type` | Yes | `application/json` |

### Body

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `query` | string | Yes | Natural language search query | `"What does the user do for work?"` |
| `user_id` | string | No | Filter results to specific user | `"user_123"` |
| `agent_id` | string | No | Filter results to specific agent | `"agent_456"` |
| `run_id` | string | No | Filter results to specific run/session | `"run_789"` |
| `limit` | integer | No | Max results to return (default: 10) | `5` |
| `threshold` | float | No | Minimum similarity score (0-1, default: 0.7) | `0.8` |
| `filters` | object | No | Additional metadata filters | `{"tags": ["important"]}` |

<CodeGroup>
```bash Shell
curl https://api.photomem.ai/v1/search \
  -H "Authorization: Bearer $PHOTOMEM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What does the user do for work?",
    "user_id": "user_123",
    "limit": 5
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.photomem.ai/v1/search",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "query": "What does the user do for work?",
        "user_id": "user_123",
        "limit": 5
    }
)
response.raise_for_status()
print(response.json())
```

```ts TypeScript
const response = await fetch("https://api.photomem.ai/v1/search", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.PHOTOMEM_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    query: "What does the user do for work?",
    user_id: "user_123",
    limit: 5
  }),
});

const data = await response.json();
console.log(data);
```
</CodeGroup>

<Tip>
  Use natural language queries for best results. PhotoMem understands context and meaning beyond simple keyword matching.
</Tip>

| Status | Meaning | Fix |
| --- | --- | --- |
| `200` | Search completed successfully | — |
| `400` | Missing or invalid query | Provide valid `query` string |
| `401` | Invalid or missing API key | Check your API key in dashboard |
| `429` | Rate limit exceeded | Slow down requests or upgrade plan |

<Note>
  Results are sorted by relevance score (highest first). The `score` represents vector similarity, while `rerank_score` (when available) provides a more refined relevance ranking.
</Note>
