PhotoMem is a high-performance memory layer for AI applications that combines the simplicity of Mem0's API with advanced features like temporal knowledge graphs, superior deduplication, and blazing-fast retrieval. Built for production workloads, PhotoMem offers 2-5x better performance while maintaining full API compatibility.

PhotoMem provides high-level APIs like `memory.add()` and `memory.search()`, supports custom entity types (user, agent, app, run), advanced filtering with complex queries, graph memory with Neo4j, and multi-tenant architecture. Mem0, by comparison, offers basic add/get/search APIs with an optional graph, but lacks built-in multi-tenancy, advanced deduplication, temporal fact management, and granular filtering.

## PhotoMem's memory model in one minute

### Unified multi-tenant architecture

* **Organizations & Projects**: Built-in multi-tenancy with organizations and projects for B2B SaaS applications. Memories are automatically isolated by organization and grouped by project.
* **Entity Types**: First-class support for `user`, `agent`, `app`, and `run` entity types, making it easy to track which part of your system created each memory.

### Superior deduplication

* PhotoMem uses **advanced content hashing and semantic similarity** to detect and prevent duplicate memories, with configurable thresholds and automatic merging of similar content.

### Temporal knowledge graph

* Every memory can be connected to a **Neo4j knowledge graph** that tracks entities, relationships, and how they evolve over time. Facts maintain creation, validation, and invalidation timestamps.

### Advanced filtering

* **Complex query builder** supports operators like `eq`, `ne`, `gt`, `lt`, `contains`, `regex`, `in`, `all`, `any`, and nested logical conditions (AND/OR/NOT) for precise memory retrieval.

### Production-ready performance

* Built on **FastAPI + PostgreSQL + Redis + Neo4j** for 2-5x faster performance than Mem0, with connection pooling, embedding caching, and batch operations.

## How PhotoMem differs from Mem0

| Capability | **PhotoMem** | **Mem0** |
| --- | --- | --- |
| **Multi-tenancy** | Native organizations & projects with full isolation | Manual implementation required |
| **Entity types** | Built-in `user`, `agent`, `app`, `run` types | Generic user_id only |
| **Knowledge graph** | Built-in Neo4j integration with temporal facts | Optional "Graph Memory" requires separate Neo4j setup |
| **Filtering** | Advanced query builder with 10+ operators & nested logic | Basic key-value filters |
| **Deduplication** | Multi-level: hash-based, semantic similarity, LLM-based | Basic hash-based only |
| **Performance** | 2-5x faster with caching, pooling, batch operations | Standard performance |
| **Search** | Hybrid semantic + keyword search with reranking | Vector search with filters |
| **LLM prompts** | Customizable, production-tested prompts for extraction/merging | Basic prompts |
| **Self-hosted** | Full source available, Docker-ready | Cloud-only for graph features |
| **Context generation** | Auto-generated, temporal, prompt-ready context blocks | Raw search results |
| **API design** | RESTful with OpenAPI specs | REST API |

## Migrating your code

### Basic flows

| **What you do in Mem0** | **Do this in PhotoMem** |
| --- | --- |
| `client.add(messages, user_id=ID)` → stores conversation | `memory.add(messages, user_id=ID, entity_type="user")` – stores with entity type |
| `client.add(messages, user_id=ID, agent_id=ID)` | `memory.add(messages, user_id=ID, agent_id=ID, organization_id=ORG, project_id=PROJ)` – multi-tenant |
| `client.search(query, user_id=ID)` – vector search | `memory.search(query, user_id=ID, limit=10)` – hybrid search with reranking |
| `client.get_all(user_id=ID)` – list memories | `memory.get_all(user_id=ID, organization_id=ORG, project_id=PROJ)` – filtered list |
| `client.update(memory_id, data)` | `memory.update(memory_id, memory="new content", metadata={...})` |
| `client.delete(memory_id)` | `memory.delete(memory_id)` |
| `client.search(query, filters={"key": "value"})` – simple filters | `memory.query(filters={"AND": [{"user_id": {"eq": ID}}, {"tags": {"contains": "work"}}]})` – complex filters |

### Practical tips

* **Organization mapping**: Create an organization for each tenant, then create projects for different use cases or environments (prod/dev).
* **Entity types**: Use `entity_type="user"` for end-users, `"agent"` for AI assistants, `"app"` for applications, and `"run"` for specific execution runs.
* **Multi-tenancy**: Always pass `organization_id` and `project_id` for proper data isolation in B2B applications.
* **Advanced filtering**: Replace simple key-value filters with PhotoMem's query builder for complex conditions.
* **Graph memory**: Enable `build_graph=True` when adding memories to automatically build knowledge graphs.

## Step-by-Step Migration

<Steps>
  <Step title="Export from Mem0">
    Mem0 provides two ways to export your memories:

    ### Option 1: Export via Dashboard (Recommended)
    
    1. Log into your [Mem0 dashboard](https://app.mem0.ai)
    2. Navigate to the export section
    3. Download your memories as JSON

    ### Option 2: Export via API
    
    Simple script to export all your memories from Mem0:

    ```python
    from mem0 import MemoryClient
    import json
    import time

    # Connect to Mem0
    client = MemoryClient(api_key="your_mem0_api_key")

    # Create export job
    schema = {
        "type": "object",
        "properties": {
            "memories": {
                "type": "array",
                "items": {
                    "type": "object",
                    "properties": {
                        "id": {"type": "string"},
                        "memory": {"type": "string"},
                        "user_id": {"type": "string"},
                        "agent_id": {"type": "string"},
                        "metadata": {"type": "object"},
                        "created_at": {"type": "string"}
                    }
                }
            }
        }
    }

    response = client.create_memory_export(schema=schema, filters={})
    export_id = response["id"]

    # Wait and retrieve
    print("Exporting memories...")
    time.sleep(5)

    export_data = client.get_memory_export(memory_export_id=export_id)

    # Save to file
    with open("mem0_export.json", "w") as f:
        json.dump(export_data, f, indent=2)

    print(f"✅ Exported {len(export_data['memories'])} memories")
    ```
  </Step>

  <Step title="Set Up PhotoMem">
    Set up your PhotoMem instance:

    ### Self-Hosted (Recommended)
    
    ```bash
    # Clone the repository
    git clone https://github.com/photomem/photomem.git
    cd photomem/backend

    # Set up environment
    cp env.example .env
    # Edit .env with your configuration

    # Start services with Docker Compose
    docker-compose up -d

    # Run migrations
    alembic upgrade head

    # Create an API key
    python scripts/create_api_key.py
    ```

    ### Cloud (Coming Soon)
    
    1. Sign up at [console.photomem.ai](https://console.photomem.ai)
    2. Create a new organization and project
    3. Generate an API key from the dashboard

    ```bash
    # Set your environment variables
    export PHOTOMEM_API_KEY="your_photomem_api_key"
    export PHOTOMEM_BASE_URL="http://localhost:8000"  # or your hosted URL
    ```
  </Step>

  <Step title="Create Organization & Project">
    Set up your organizational structure in PhotoMem:

    ```python
    import requests

    base_url = "http://localhost:8000"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    }

    # Create organization
    org_response = requests.post(
        f"{base_url}/v1/organizations",
        headers=headers,
        json={
            "name": "My Company",
            "slug": "my-company",
            "settings": {"features": ["graph_memory", "advanced_filtering"]}
        }
    )
    org = org_response.json()
    print(f"✅ Created organization: {org['id']}")

    # Create project
    project_response = requests.post(
        f"{base_url}/v1/projects",
        headers=headers,
        json={
            "organization_id": org["id"],
            "name": "Production",
            "slug": "production",
            "description": "Production memories from Mem0 migration"
        }
    )
    project = project_response.json()
    print(f"✅ Created project: {project['id']}")
    ```
  </Step>

  <Step title="Import to PhotoMem">
    Import your Mem0 memories into PhotoMem with enhanced metadata:

    ```python
    import json
    from photomem import Memory

    # Load your Mem0 export
    with open("mem0_export.json", "r") as f:
        mem0_data = json.load(f)

    # Connect to PhotoMem
    memory = Memory(
        api_key="your_photomem_api_key",
        base_url="http://localhost:8000"
    )

    # Import memories
    imported = 0
    failed = 0

    for mem in mem0_data["memories"]:
        content = mem.get("memory", "")
        
        # Skip empty memories
        if not content:
            continue

        try:
            # Determine entity type
            entity_type = "user"  # Default
            if mem.get("agent_id"):
                entity_type = "agent"
            elif mem.get("run_id"):
                entity_type = "run"

            # Import to PhotoMem with full context
            result = await memory.add(
                messages=[{"role": "user", "content": content}],
                organization_id=org["id"],
                project_id=project["id"],
                user_id=mem.get("user_id"),
                agent_id=mem.get("agent_id"),
                run_id=mem.get("run_id"),
                entity_type=entity_type,
                tags=["imported_from_mem0"] + (mem.get("metadata", {}).get("tags", [])),
                metadata={
                    "source": "mem0",
                    "original_id": mem.get("id"),
                    "created_at": mem.get("created_at"),
                    **(mem.get("metadata") or {})
                },
                build_graph=True,  # Build knowledge graph
                deduplicate=True   # Enable smart deduplication
            )
            
            imported += 1
            print(f"✅ Imported: {content[:50]}...")
            
        except Exception as e:
            failed += 1
            print(f"❌ Failed: {str(e)}")

    print(f"\n🎉 Migration complete!")
    print(f"   Imported: {imported}")
    print(f"   Failed: {failed}")
    ```
  </Step>

  <Step title="Verify Migration">
    Test that your memories were imported correctly:

    ```python
    # Search for imported memories
    results = await memory.search(
        query="test search",
        organization_id=org["id"],
        project_id=project["id"],
        limit=5
    )

    print(f"Found {len(results)} memories")
    for result in results:
        print(f"  - {result['memory'][:50]}... (score: {result['score']:.2f})")

    # Test advanced filtering
    filtered = await memory.query(
        filters={
            "AND": [
                {"tags": {"contains": "imported_from_mem0"}},
                {"entity_type": {"eq": "user"}}
            ]
        },
        organization_id=org["id"],
        project_id=project["id"]
    )

    print(f"\nFiltered results: {len(filtered)} memories")
    ```
  </Step>
</Steps>

## Quick Migration (All-in-One)

Complete migration in one script:

```python
from mem0 import MemoryClient
from photomem import Memory
import json
import time
import requests

# ============================================================================
# STEP 1: Export from Mem0
# ============================================================================
print("📦 Exporting from Mem0...")

mem0 = MemoryClient(api_key="your_mem0_api_key")

export = mem0.create_memory_export(
    schema={
        "type": "object",
        "properties": {
            "memories": {"type": "array", "items": {"type": "object"}}
        }
    },
    filters={}
)

time.sleep(5)
data = mem0.get_memory_export(memory_export_id=export["id"])
print(f"✅ Exported {len(data['memories'])} memories")

# ============================================================================
# STEP 2: Set up PhotoMem organization
# ============================================================================
print("\n🏢 Setting up PhotoMem...")

photomem_api_key = "your_photomem_api_key"
base_url = "http://localhost:8000"
headers = {
    "Authorization": f"Bearer {photomem_api_key}",
    "Content-Type": "application/json"
}

# Create organization
org = requests.post(
    f"{base_url}/v1/organizations",
    headers=headers,
    json={"name": "My Company", "slug": "my-company"}
).json()

# Create project
project = requests.post(
    f"{base_url}/v1/projects",
    headers=headers,
    json={
        "organization_id": org["id"],
        "name": "Production",
        "slug": "production"
    }
).json()

print(f"✅ Organization: {org['id']}")
print(f"✅ Project: {project['id']}")

# ============================================================================
# STEP 3: Import to PhotoMem
# ============================================================================
print("\n📥 Importing to PhotoMem...")

memory = Memory(api_key=photomem_api_key, base_url=base_url)

imported = 0
for mem in data["memories"]:
    if mem.get("memory"):
        try:
            await memory.add(
                messages=[{"role": "user", "content": mem["memory"]}],
                organization_id=org["id"],
                project_id=project["id"],
                user_id=mem.get("user_id"),
                agent_id=mem.get("agent_id"),
                entity_type="user" if mem.get("user_id") else "agent",
                tags=["imported_from_mem0"],
                metadata={"source": "mem0", "original_id": mem.get("id")},
                build_graph=True,
                deduplicate=True
            )
            imported += 1
            print(f"✅ {mem['memory'][:50]}...")
        except Exception as e:
            print(f"❌ Error: {e}")

print(f"\n🎉 Migration complete! Imported {imported} memories")
```

## Side-by-side SDK comparison

| **Operation** | Mem0 Method (Python) | PhotoMem Method (Python) | Notes |
| --- | --- | --- | --- |
| Add chat messages | `m.add(messages, user_id=...)` | `memory.add(messages, user_id=..., entity_type="user")` | PhotoMem adds entity type tracking |
| Add with organization | *not supported* | `memory.add(..., organization_id=ORG, project_id=PROJ)` | Built-in multi-tenancy |
| Semantic search | `m.search(query, user_id=...)` | `memory.search(query, user_id=..., threshold=0.7)` | PhotoMem has configurable threshold |
| Complex filtering | `m.search(..., filters={"key": "val"})` | `memory.query(filters={"AND": [...]})` | Advanced query builder |
| List memories | `m.get_all(user_id=...)` | `memory.get_all(user_id=..., limit=100)` | Supports pagination |
| Update memory | `m.update(id, data=...)` | `memory.update(id, memory="...", metadata={...})` | Maintains history |
| Delete memory | `m.delete(id)` | `memory.delete(id)` | Same API |
| Graph relations | `m.get_relations(...)` (if graph enabled) | Built-in via `build_graph=True` | Automatic entity extraction |

## API migration reference

Here's how common Mem0 operations map to PhotoMem:

### Adding Memories

<CodeGroup>

```python Mem0
from mem0 import MemoryClient

client = MemoryClient(api_key="...")

client.add(
    messages=[{"role": "user", "content": "User prefers dark mode"}],
    user_id="phone:15103651277"
)
```

```python PhotoMem
from photomem import Memory

memory = Memory(api_key="...")

await memory.add(
    messages=[{"role": "user", "content": "User prefers dark mode"}],
    user_id="phone:15103651277",
    entity_type="user",
    organization_id="org_abc123",
    project_id="proj_xyz789",
    tags=["preferences", "ui"]
)
```

</CodeGroup>

### Searching Memories

<CodeGroup>

```python Mem0
results = client.search(
    query="user preferences",
    user_id="phone:15103651277"
)
```

```python PhotoMem
results = await memory.search(
    query="user preferences",
    user_id="phone:15103651277",
    organization_id="org_abc123",
    project_id="proj_xyz789",
    limit=10,
    threshold=0.7
)
```

</CodeGroup>

### Advanced Filtering

<CodeGroup>

```python Mem0
# Basic key-value filtering
results = client.search(
    query="preferences",
    user_id="alice",
    filters={"category": "ui"}
)
```

```python PhotoMem
# Complex query builder
results = await memory.query(
    filters={
        "AND": [
            {"user_id": {"eq": "phone:15103651277"}},
            {"tags": {"contains": "preferences"}},
            {
                "OR": [
                    {"metadata.category": {"eq": "ui"}},
                    {"metadata.category": {"eq": "ux"}}
                ]
            }
        ]
    },
    organization_id="org_abc123",
    project_id="proj_xyz789"
)
```

</CodeGroup>

### Getting All Memories

<CodeGroup>

```python Mem0
memories = client.get_all(
```

```python PhotoMem
memories = await memory.get_all(
    user_id="phone:15103651277",
    organization_id="org_abc123",
    project_id="proj_xyz789",
    limit=100,
    offset=0
)
```

</CodeGroup>
