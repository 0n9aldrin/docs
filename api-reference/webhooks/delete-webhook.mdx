## Path Parameters

<ParamField path="org_id" type="string" required>
  Organization identifier
</ParamField>

<ParamField path="project_id" type="string" required>
  Project identifier
</ParamField>

<ParamField path="webhook_id" type="string" required>
  Webhook identifier
</ParamField>

## Response

<ResponseField name="message" type="string">
  Confirmation message
</ResponseField>

<ResponseField name="deletedAt" type="string">
  Deletion timestamp
</ResponseField>

<RequestExample>

```bash cURL
curl -X DELETE "https://api.photomem.io/api/organizations/{org_id}/projects/{project_id}/webhooks/{webhook_id}" \
  -H "Authorization: Bearer YOUR_CLERK_TOKEN"
```

```python Python
import requests

response = requests.delete(
    f"https://api.photomem.io/api/organizations/{org_id}/projects/{project_id}/webhooks/{webhook_id}",
    headers={"Authorization": f"Bearer {clerk_token}"}
)

result = response.json()
print(result["message"])
```

```typescript TypeScript
const response = await fetch(
  `https://api.photomem.io/api/organizations/${orgId}/projects/${projectId}/webhooks/${webhookId}`,
  {
    method: 'DELETE',
    headers: {
      'Authorization': `Bearer ${clerkToken}`
    }
  }
);

const result = await response.json();
console.log(result.message);
```
