---
title: 'Get User Profile'
openapi: get /api/users/me
---

Get the currently authenticated user's profile information.

## Authentication

This endpoint requires JWT authentication.

```bash
Authorization: Bearer YOUR_JWT_TOKEN
```

## Response

<ResponseField name="id" type="string">
  Unique user identifier
</ResponseField>

<ResponseField name="email" type="string">
  User's email address
</ResponseField>

<ResponseField name="name" type="string">
  User's full name
</ResponseField>

<ResponseField name="imageUrl" type="string">
  Profile image URL (null if not set)
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 timestamp of account creation
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET https://api.photomem.ai/api/users/me \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

```typescript TypeScript
const response = await fetch('https://api.photomem.ai/api/users/me', {
  headers: {
    'Authorization': `Bearer ${jwtToken}`
  }
});

const profile = await response.json();
console.log(`Hello, ${profile.name}!`);
```

```python Python
import requests

response = requests.get(
    "https://api.photomem.ai/api/users/me",
    headers={"Authorization": f"Bearer {jwt_token}"}
)

profile = response.json()
print(f"Hello, {profile['name']}!")
```
