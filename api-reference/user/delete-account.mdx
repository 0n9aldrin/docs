---
title: "Delete Account"
api: "DELETE /api/users/me"
description: "Delete user account (soft delete with grace period)"
---

<Warning>
  This action marks your account for deletion. After 30 days, all data will be permanently deleted.
</Warning>

## Query Parameters

<ParamField query="confirmation" type="string" required>
  Must be the string "DELETE" to confirm deletion
</ParamField>

## Response

<ResponseField name="message" type="string">
  Confirmation message
</ResponseField>

<ResponseField name="deletedAt" type="string">
  Deletion timestamp
</ResponseField>

<ResponseField name="gracePeriodDays" type="number">
  Grace period in days
</ResponseField>

<RequestExample>

```bash cURL
curl -X DELETE "https://api.photomem.io/api/users/me?confirmation=DELETE" \
  -H "Authorization: Bearer YOUR_CLERK_TOKEN"
```

```python Python
import requests

response = requests.delete(
    "https://api.photomem.io/api/users/me",
    params={"confirmation": "DELETE"},
    headers={"Authorization": f"Bearer {clerk_token}"}
)

result = response.json()
print(result["message"])
```

```typescript TypeScript
const response = await fetch(
  'https://api.photomem.io/api/users/me?confirmation=DELETE',
  {
    method: 'DELETE',
    headers: {
      'Authorization': `Bearer ${clerkToken}`
    }
  }
);

const result = await response.json();
console.log(result.message);
```

</RequestExample>
