## Prerequisites

<AccordionGroup>
  <Accordion title="PostgreSQL with pgvector" icon="database">
    PhotoMem uses PostgreSQL with the pgvector extension for vector storage.
    
    **Quick Setup with Docker:**
    ```bash
    docker run -d \
      --name photomem-postgres \
      -e POSTGRES_PASSWORD=postgres \
      -e POSTGRES_DB=photomem \
      -p 5432:5432 \
      pgvector/pgvector:pg16
    ```
  </Accordion>

  <Accordion title="OpenAI API Key" icon="key">
    Get your API key from [OpenAI Platform](https://platform.openai.com/api-keys)
    
    ```bash
    export OPENAI_API_KEY="sk-..."
    ```
  </Accordion>

  <Accordion title="Python 3.11+ or Node.js 18+" icon="code">
    - **Python**: 3.11 or later
    - **Node.js**: 18 or later (for TypeScript)
  </Accordion>
</AccordionGroup>

## Your First Memory

<Tabs>
  <Tab title="Python">
    Create a file called `example.py`:

    ```python
    import asyncio
    from photomem import Memory

    async def main():
        # 1. Initialize Memory
        memory = Memory()
        await memory.initialize()
        
        try:
            # 2. Add a memory
            result = await memory.add(
                "I love hiking in the mountains",
                user_id="phone:15103651277"
            )
            print(f"✅ Added: {result.memory}")
            print(f"📝 Memory ID: {result.id}")
            
            # 3. Search memories
            results = await memory.search(
                "What outdoor activities do I enjoy?",
                user_id="phone:15103651277"
            )
            
            print(f"\n🔍 Found {len(results)} memories:")
            for r in results:
                print(f"  • {r.memory} (score: {r.score:.2f})")
        
        finally:
            # 4. Always close connections
            await memory.close()

    # Run the example
    asyncio.run(main())
    ```

    Run it:
    ```bash
    python example.py
    ```
  </Tab>
  
  <Tab title="TypeScript">
    Create a file called `example.ts`:

    ```typescript
    import { Memory } from 'photomem';

    async function main() {
        // 1. Initialize Memory
        const memory = new Memory();
        await memory.initialize();
        
        try {
            // 2. Add a memory
            const result = await memory.add(
                'I love hiking in the mountains',
                { userId: 'phone:15103651277' }
            );
            console.log(`✅ Added: ${result.memory}`);
            console.log(`📝 Memory ID: ${result.id}`);
            
            // 3. Search memories
            const results = await memory.search(
                'What outdoor activities do I enjoy?',
                { userId: 'phone:15103651277' }
            );
            
            console.log(`\n🔍 Found ${results.length} memories:`);
            results.forEach(r => {
                console.log(`  • ${r.memory} (score: ${r.score.toFixed(2)})`);
            });
        } finally {
            // 4. Always close connections
            await memory.close();
        }
    }

    main();
    ```

    Run it:
    ```bash
    npx tsx example.ts
    ```
  </Tab>
</Tabs>

## What Just Happened?

<Steps>
  <Step title="Initialization">
    PhotoMem connected to PostgreSQL and OpenAI, setting up connection pools and caches.
  </Step>
  
  <Step title="Fact Extraction">
    Your message was sent to the LLM which extracted the key fact: "Loves hiking in the mountains"
  </Step>
  
  <Step title="Embedding Generation">
    The fact was converted to a 1536-dimensional vector using OpenAI's text-embedding-3-small
  </Step>
  
  <Step title="Storage">
    The vector and metadata were stored in PostgreSQL with pgvector indexing
  </Step>
  
  <Step title="Semantic Search">
    Your query was embedded and compared using cosine similarity to find relevant memories
  </Step>
</Steps>

## Using Docker Compose

For a complete setup with all services, use docker-compose:

```bash
cd photomem/python/server
docker-compose up -d
```

This starts:
- PostgreSQL with pgvector
- Redis (for caching)
- FastAPI server (REST API)

Then connect to the API:

```python
import httpx

async with httpx.AsyncClient() as client:
    response = await client.post(
        "http://localhost:8000/memories",
        json={
            "messages": "I love pizza",
            "user_id": "phone:15103651277"
        }
    )
    print(response.json())
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Connection refused" icon="wifi">
    Make sure PostgreSQL is running:
    ```bash
    docker ps | grep postgres
    ```
    
    Test the connection:
    ```bash
    psql postgresql://postgres:postgres@localhost:5432/photomem
    ```
  </Accordion>

  <Accordion title="OpenAI API errors" icon="exclamation-triangle">
    Verify your API key:
    ```bash
    echo $OPENAI_API_KEY
    ```
    
    Test it with curl:
    ```bash
    curl https://api.openai.com/v1/models \
      -H "Authorization: Bearer $OPENAI_API_KEY"
    ```
  </Accordion>

  <Accordion title="Import errors" icon="circle-xmark">
    Reinstall with all dependencies:
    ```bash
    pip install -e ".[all]"
    ```
    
    Or for TypeScript:
    ```bash
    npm install --force
    ```
  </Accordion>
</AccordionGroup>
