## Overview

Retrieve a list of memories with optional filtering by user, agent, run, tags, and memory type. This endpoint supports pagination for large result sets.

<Info>
Use this endpoint when you need to fetch all memories for a given entity or want to browse memories with specific attributes. For semantic search, use [Search Memories](/api-reference/memory/search-memories).
</Info>

## Query Parameters

<ParamField query="user_id" type="string">
  Filter memories by user ID. Returns only memories associated with this user.
</ParamField>

<ParamField query="agent_id" type="string">
  Filter memories by agent ID. Returns only memories associated with this agent.
</ParamField>

<ParamField query="run_id" type="string">
  Filter memories by run/session ID. Returns only memories from a specific conversation session.
</ParamField>

<ParamField query="tags" type="array">
  Filter memories by tags. Can be specified multiple times to filter by multiple tags.
  
  **Example:** `?tags=work&tags=important`
</ParamField>

<ParamField query="memory_type" type="string">
  Filter by memory type (e.g., `fact`, `preference`, `short_term`, `long_term`).
</ParamField>

<ParamField query="limit" type="integer" default="100">
  Maximum number of memories to return. Must be between 1 and 1000.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of memories to skip for pagination. Must be >= 0.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.photomem.ai/v1/memories?user_id=user_123&limit=50&offset=0" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import httpx

async def get_memories(api_key: str, user_id: str, limit: int = 100, offset: int = 0):
    async with httpx.AsyncClient() as client:
        response = await client.get(
            "https://api.photomem.ai/v1/memories",
            headers={"Authorization": f"Bearer {api_key}"},
            params={
                "user_id": user_id,
                "limit": limit,
                "offset": offset,
            },
        )
        response.raise_for_status()
        return response.json()

# Example usage:
# memories = await get_memories("YOUR_API_KEY", "user_123", limit=50)
```

```javascript TypeScript
async function getMemories(
  apiKey: string,
  userId: string,
  limit: number = 100,
  offset: number = 0
): Promise<any> {
  const params = new URLSearchParams({
    user_id: userId,
    limit: limit.toString(),
    offset: offset.toString(),
  });

  const response = await fetch(
    `https://api.photomem.ai/v1/memories?${params}`,
    {
      headers: {
        Authorization: `Bearer ${apiKey}`,
      },
    }
  );

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  return response.json();
}

// Example usage:
// const memories = await getMemories("YOUR_API_KEY", "user_123", 50, 0);
```
</RequestExample>

</Tip>

## Response

<ResponseField name="memories" type="array">
  Array of memory objects matching the query filters.
  
  <Expandable title="Memory Object">
    <ResponseField name="id" type="string">
      Unique identifier for the memory
    </ResponseField>
    
    <ResponseField name="memory" type="string">
      The extracted memory text/fact
    </ResponseField>
    
    <ResponseField name="hash" type="string">
      Content hash for deduplication
    </ResponseField>
    
    <ResponseField name="metadata" type="object">
      <Expandable title="Metadata Fields">
        <ResponseField name="user_id" type="string">

        </ResponseField>
        
        <ResponseField name="agent_id" type="string">
          Agent ID associated with the memory
        </ResponseField>
        
        <ResponseField name="run_id" type="string">
          Run/session ID associated with the memory

        <ResponseField name="tags" type="array">

        </ResponseField>

          ISO 8601 timestamp when memory was last updated

      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

| Status | Meaning | Fix |
| --- | --- | --- |
| `200` | Success - returns array of memories | — |
| `400` | Invalid query parameters | Check that limit is 1-1000 and offset >= 0 |
| `401` | Authentication failed | Verify API key in Authorization header |

<Note>
Empty result set returns `[]`. Use `offset` and `limit` for pagination through large result sets.
</Note>
