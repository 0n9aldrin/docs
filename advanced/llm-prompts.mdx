## Overview

PhotoMem uses **state-of-the-art prompts** engineered with industry best practices for:
- **High-quality fact extraction** - Capture meaningful, specific information
- **Intelligent merging** - Consolidate duplicate or related memories
- **Smart updates** - Handle corrections and incremental changes
- **Conflict resolution** - Resolve contradictions automatically
- **Entity recognition** - Extract people, places, organizations, and more

<Note>
These prompts are the result of extensive testing and are significantly better than basic extraction approaches.
</Note>

## Memory Extraction

### What It Does

Extracts factual, long-term memories from conversations while filtering out:
- ❌ Conversational filler ("hi", "thanks", "goodbye")
- ❌ Temporary information (weather today, current time)
- ❌ Obvious facts (water is wet)
- ❌ Questions without answers

### Quality Standards

## Memory Merging

### Strategies

<AccordionGroup>
  <Accordion title="Near-Duplicates" icon="copy">
    **Keep the more detailed version**
    
    ```
    Existing: "User likes coffee"
    New: "User enjoys specialty coffee"
    → Merged: "User enjoys specialty coffee"
    ```
  </Accordion>
  
  <Accordion title="Complementary Information" icon="puzzle-piece">
    **Combine both**
    
    ```
    Existing: "User works at Google"
    New: "User is a Senior Engineer at Google in Mountain View"
    → Merged: "User is a Senior Engineer at Google in Mountain View"
    ```
  </Accordion>
  
  <Accordion title="Temporal Updates" icon="clock-rotate-left">
    **Prefer recent, preserve history**
    
    ```
    Existing: "User lived in New York"
    New: "User moved to San Francisco in January 2024"
    → Merged: "User moved to San Francisco in January 2024 (previously lived in New York)"
    ```
  </Accordion>
  
  <Accordion title="Contradictions" icon="triangle-exclamation">
    **Choose recent, note change**
    
    ```
    Existing: "User is vegetarian"
    New: "User started eating meat again in December 2023"
    → Merged: "User started eating meat again in December 2023 (was previously vegetarian)"
    ```
  </Accordion>
  
  <Accordion title="Different Aspects" icon="layer-group">
    **Keep both in one sentence**
    
    ```
    Existing: "User speaks English and Spanish"
    New: "User is learning Japanese"
    → Merged: "User speaks English and Spanish, and is currently learning Japanese"
    ```
  </Accordion>
</AccordionGroup>

### Usage

```python
from photomem import Memory

memory = Memory()
await memory.initialize()

# Automatic merging on add
result = await memory.add(
    "I work at Google as a Senior Engineer",
    user_id="phone:123",
    deduplicate=True  # Enable merging (default)
)

# If a similar memory exists, it will be automatically merged
```

## Memory Updates

### Update Types

<Tabs>
  <Tab title="Refinement">
    **Adding detail without contradiction**
    
    ```
    Current: "User works at Microsoft"
    New: "as a Principal Engineer"
    → Updated: "User works as a Principal Engineer at Microsoft"
    ```
    
    ```python
    await memory.update(
        memory_id="mem_123",
        data="User works as a Principal Engineer at Microsoft"
    )
    ```
  </Tab>
  
  <Tab title="Correction">
    **Fixing errors**
    
    ```
    Current: "User lives in Boston"
    New: "Actually lives in Cambridge"
    → Updated: "User lives in Cambridge"
    ```
    
    ```python
    await memory.update(
        memory_id="mem_123",
        data="User lives in Cambridge"
    )
    ```
  </Tab>
  
  <Tab title="Temporal Update">
    **Change over time**
    
    ```
    Current: "User is single"
    New: "got married in June 2024"
    → Updated: "User got married in June 2024"
    ```
    
    ```python
    await memory.update(
        memory_id="mem_123",
        data="User got married in June 2024"
    )
    ```
  </Tab>
  
  <Tab title="Addition">
    **New aspect**
    
    ```
    Current: "User speaks French"
    New: "and Italian fluently"
    → Updated: "User speaks French and Italian fluently"
    ```
    
    ```python
    await memory.update(
        memory_id="mem_123",
        data="User speaks French and Italian fluently"
    )
    ```
  </Tab>
</Tabs>

## Conflict Resolution

When multiple memories contain contradictory information:

### Resolution Strategies

<Steps>
  <Step title="Temporal Ordering">
    If memories represent changes over time, preserve timeline
    
    ```
    Memory 1: "User lived in Boston"
    Memory 2: "User moved to Seattle in 2023"
    → Resolved: "User moved to Seattle in 2023 (previously lived in Boston)"
    ```
  </Step>
  
  <Step title="Detail vs Generic">
    Choose more specific version
    
    ```
    Memory 1: "User works in tech"
    Memory 2: "User is a Senior ML Engineer at DeepMind"
    → Resolved: Keep Memory 2 (more specific)
    ```
  </Step>
  
  <Step title="Direct Contradictions">
    Prefer most recent or specific
    
    ```
    Memory 1: "User is vegetarian"
    Memory 2: "User started eating fish in January 2024"
    → Resolved: "User started eating fish in January 2024 (was previously vegetarian)"
    ```
  </Step>
  
  <Step title="Partial Overlap">
    Merge complementary information
    
    ```
    Memory 1: "User speaks English and Spanish"
    Memory 2: "User speaks Spanish and French"
    → Resolved: "User speaks English, Spanish, and French"
    ```
  </Step>
</Steps>

## Entity Extraction

### Supported Entity Types

| Type | Examples | Use Cases |
|------|----------|-----------|
| **PERSON** | "John Smith", "Dr. Sarah" | Contact management, relationship tracking |
| **LOCATION** | "San Francisco", "Golden Gate Park" | Location-based memory, travel history |
| **ORGANIZATION** | "Google", "Harvard" | Work history, affiliations |
| **DATE** | "June 2024", "every Monday" | Temporal context, scheduling |
| **PRODUCT** | "iPhone 15", "Python" | Preferences, technical stack |
| **EVENT** | "TechCrunch Disrupt", "Christmas" | Event memory, planning |
| **SKILL** | "machine learning", "Spanish" | Capability tracking, learning |

### Example

```python
# Automatic entity extraction
result = await memory.add(
    "I work at Google in Mountain View and use Python daily",
    user_id="phone:123",
    infer_entities=True  # Default
)

print(result.entities)
# [
#   {"type": "ORGANIZATION", "name": "Google"},
#   {"type": "LOCATION", "name": "Mountain View"},
#   {"type": "PRODUCT", "name": "Python"}
# ]
```

## Configuration

### Temperature Settings

Different operations use optimized temperatures:

```python
# Extraction (consistency)
temperature=0.3

# Merging (deterministic)
temperature=0.2

# Updates (deterministic)
temperature=0.2

# Deletion decisions (conservative)
temperature=0.1

# Entity extraction (precise)
temperature=0.1
```

### Custom Prompts

You can customize prompts if needed:

```python
from photomem.llm import OpenAILLM
from photomem.llm.prompts import MemoryPrompts

# Custom extraction prompt
custom_prompt = MemoryPrompts.extract_memories(
    actor="user",
    user_id="phone:123"
)

llm = OpenAILLM(api_key="...", model="gpt-4")
memories = await llm.extract_memories(
    messages=[...],
    custom_prompt=custom_prompt
)
```

## Best Practices

<AccordionGroup>
  <Accordion title="Let the LLM Work" icon="wand-magic-sparkles">
    Don't over-process text before extraction - the LLM handles:
    - Normalization
    - Typo correction
    - Context understanding
    - Entity recognition
  </Accordion>
  
  <Accordion title="Provide Context" icon="messages">
    Include full conversation context, not just the latest message:
    ```python
    await memory.add(
        messages=[
            {"role": "user", "content": "I love hiking"},
            {"role": "assistant", "content": "Where?"},
            {"role": "user", "content": "In the Swiss Alps"}
        ],
        user_id="phone:123"
    )
    ```
  </Accordion>
  
  <Accordion title="Enable Deduplication" icon="clone">
    Always use deduplication for quality:
    ```python
    await memory.add(
        "...",
        user_id="phone:123",
        deduplicate=True  # Default
    )
    ```
  </Accordion>
  
  <Accordion title="Monitor Quality" icon="chart-line">
    Review extracted memories periodically:
    ```python
    memories = await memory.list(user_id="phone:123")
    for mem in memories:
        print(mem.memory)
        print(mem.entities)
    ```
  </Accordion>
</AccordionGroup>
