---
title: "Get Memories"
api: "GET /v1/memories/"
description: "Retrieve all memories for a specific user"
---

## Overview

Retrieve all stored memories for a user. Results are paginated and sorted by creation date (newest first).

## Query Parameters

<ParamField query="user_id" type="string" required>
  User ID to retrieve memories for
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Maximum number of memories to return per page. Range: 1-100
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of memories to skip for pagination
</ParamField>

## Response

<ResponseField name="memories" type="array">
  Array of user memories sorted by creation date (newest first).

  <Expandable title="Memory Object">
    <ResponseField name="id" type="string">
      Unique identifier for the memory
    </ResponseField>

    <ResponseField name="content" type="string">
      The memory content
    </ResponseField>

    <ResponseField name="user_id" type="string">
      User ID associated with this memory
    </ResponseField>

    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the memory was created
    </ResponseField>

    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of last update
    </ResponseField>

    <ResponseField name="metadata" type="object">
      Metadata attached to the memory
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of memories for this user
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Whether there are more results available for pagination
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET 'https://api.photomem.ai/v1/memories/?user_id=user_123&limit=10' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

url = "https://api.photomem.ai/v1/memories/"
headers = {
    "Authorization": "Bearer YOUR_API_KEY"
}
params = {
    "user_id": "user_123",
    "limit": 10
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript JavaScript
const params = new URLSearchParams({
  user_id: 'user_123',
  limit: '10'
});

const response = await fetch(`https://api.photomem.ai/v1/memories/?${params}`, {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});

const data = await response.json();
console.log(data);
```
