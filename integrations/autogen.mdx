## AutoGen Integration

Add persistent memory to your AutoGen conversational agents with PhotoMem.

<Info>
This integration guide is coming soon! Check back for updates or [join our Discord](https://discord.gg/photomem) for early access.
</Info>

## Quick Example

```python
from autogen import AssistantAgent
from photomem import PhotoMem

# Initialize PhotoMem
memory = PhotoMem(api_key="your-api-key")

# Create agent with memory
assistant = AssistantAgent(
    name="assistant",
    memory=memory
)
```
