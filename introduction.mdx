## Use Cases

PhotoMem powers memory for various AI applications:

- **AI Assistants**: Build chatbots that remember user preferences and context
- **Agent Systems**: Create agents with persistent knowledge and learning
- **Customer Support**: Provide personalized support with conversation history
- **Recommendation Engines**: Improve recommendations with user interaction memory

## How It Works

PhotoMem provides a simple REST API to:

1. **Store memories** from user interactions and conversations
2. **Search memories** using semantic similarity and filters
3. **Update memories** to reflect new information or corrections
4. **Delete memories** when users request data removal
