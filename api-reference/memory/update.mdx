---
title: "Update Memory"
api: "PATCH /v1/memories/{memory_id}/"
description: "Update an existing memory's content or metadata"
---

## Overview

Update the content or metadata of an existing memory. This is useful for correcting information or adding additional context.

## Path Parameters

<ParamField path="memory_id" type="string" required>
  Unique identifier of the memory to update
</ParamField>

## Request Body

<ParamField body="content" type="string">
  New content for the memory
</ParamField>

<ParamField body="metadata" type="object">
  New or updated metadata fields
</ParamField>

<Info>
You must provide at least one of `content` or `metadata` in the request body.
</Info>

## Response

<ResponseField name="memory" type="object">
  The updated memory object.

  <Expandable title="Memory Object">
    <ResponseField name="id" type="string">
      Unique identifier for the memory
    </ResponseField>

    <ResponseField name="content" type="string">
      The updated memory content
    </ResponseField>

    <ResponseField name="user_id" type="string">
      User ID associated with this memory
    </ResponseField>

    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the memory was created
    </ResponseField>

    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of last update
    </ResponseField>

    <ResponseField name="metadata" type="object">
      Updated metadata
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X PATCH 'https://api.photomem.ai/v1/memories/mem_abc123/' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "content": "User'\''s name is Sarah Johnson",
    "metadata": {
      "verified": true
    }
  }'
```

```python Python
import requests

url = "https://api.photomem.ai/v1/memories/mem_abc123/"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "content": "User's name is Sarah Johnson",
    "metadata": {
        "verified": True
    }
}

response = requests.patch(url, json=data, headers=headers)
print(response.json())
```

```javascript JavaScript
const response = await fetch('https://api.photomem.ai/v1/memories/mem_abc123/', {
  method: 'PATCH',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    content: "User's name is Sarah Johnson",
    metadata: {
      verified: true
    }
  })
});

const data = await response.json();
console.log(data);
```
