## Overview

The Personalized AI Companion leverages PhotoMem to retain information across interactions, enabling a tailored learning experience. It creates memories for each user interaction and integrates with OpenAI's GPT models to provide detailed and context-aware responses to user queries.

## Setup

Before you begin, follow these steps to set up the demo application:

1. Clone the PhotoMem repository:
   ```bash
   git clone https://github.com/photomemai/photomem.git
   ```

2. Navigate to the demo application folder:
   ```bash
   cd photomem/examples/photomem-demo
   ```

3. Install dependencies:
   ```bash
   pnpm install
   ```

4. Set up environment variables by creating a `.env` file in the project root with the following content:
   ```bash
   OPENAI_API_KEY=your_openai_api_key
   PHOTOMEM_API_KEY=your_photomem_api_key
   ```
   You can obtain your `PHOTOMEM_API_KEY` by signing up at [PhotoMem API Dashboard](https://app.photomem.ai/dashboard/api-keys).

5. Start the development server:
   ```bash
   pnpm run dev
   ```
