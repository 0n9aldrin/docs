---
title: "Update Memory"
api: "PATCH /api/v1/memories/{memory_id}"
description: "Update an existing memory"
---

## Path Parameters

<ParamField path="memory_id" type="string" required>
  Memory identifier
</ParamField>

## Request Body

<ParamField body="content" type="string">
  New content (max 10KB)
</ParamField>

<ParamField body="tags" type="array">
  New tags array
</ParamField>

## Response

<ResponseField name="memory" type="object">
  Updated memory object
</ResponseField>

<RequestExample>

```bash cURL
curl -X PATCH "https://api.photomem.io/api/v1/memories/mem_abc123xyz" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "User prefers dark mode and large font size",
    "tags": ["preference", "ui", "accessibility"]
  }'
```

```python Python
import requests

response = requests.patch(
    f"https://api.photomem.io/api/v1/memories/{memory_id}",
    headers={
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    },
    json={
        "content": "User prefers dark mode and large font size",
        "tags": ["preference", "ui", "accessibility"]
    }
)

memory = response.json()["memory"]
print(f"Updated: {memory['id']}")
```

```typescript TypeScript
const response = await fetch(
  `https://api.photomem.io/api/v1/memories/${memoryId}`,
  {
    method: 'PATCH',
    headers: {
      'Authorization': `Bearer ${apiKey}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      content: 'User prefers dark mode and large font size',
      tags: ['preference', 'ui', 'accessibility']
    })
  }
);

const { memory } = await response.json();
console.log(`Updated: ${memory.id}`);
```
