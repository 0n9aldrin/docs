## Overview

PhotoMem features a **super developer-friendly filtering system** that lets you build complex queries with intuitive syntax. No need to learn complicated query languages!

## Quick Start

### Simple Equality

The most common case - just pass the value directly:

<CodeGroup>
```python Python
results = await memory.query({
    "filter": {
        "user_id": "phone:15103651277"
    }
})
```

```typescript TypeScript
const results = await memory.query({
  filter: {
    userId: 'phone:15103651277'
  }
});
```

```bash REST API
curl -X POST http://localhost:8000/v1/memories/query \
  -H "Authorization: Bearer pm_sk_xxxxx" \
  -d '{
    "filter": {
      "user_id": "phone:15103651277"
    }
  }'
```
</CodeGroup>

## Filter Operations

### Comparison Operators

<ParamField path="eq" type="any">
  Equals - exact match
</ParamField>

<ParamField path="ne" type="any">
  Not equals
</ParamField>

<ParamField path="gt" type="number | date">
  Greater than
</ParamField>

<ParamField path="gte" type="number | date">
  Greater than or equal
</ParamField>

<ParamField path="lt" type="number | date">
  Less than
</ParamField>

<ParamField path="lte" type="number | date">
  Less than or equal
</ParamField>

### String Operators

<ParamField path="contains" type="string">
  Contains substring (case-insensitive)
</ParamField>

<ParamField path="startswith" type="string">
  Starts with prefix
</ParamField>

<ParamField path="endswith" type="string">
  Ends with suffix
</ParamField>

<ParamField path="regex" type="string">
  Regex pattern match
</ParamField>

### List Operators

<ParamField path="in" type="array">
  Value is in list
</ParamField>

<ParamField path="nin" type="array">
  Value not in list
</ParamField>

<ParamField path="all" type="array">
  Array contains all values
</ParamField>

<ParamField path="any" type="array">
  Array contains any value
</ParamField>

### Special Operators

<ParamField path="is_null" type="boolean">
  Check if field is null/empty
</ParamField>

<ParamField path="search" type="string">
  Full-text search (PostgreSQL tsvector)
</ParamField>

## Examples

### Text Search

Find memories containing specific keywords:

<CodeGroup>
```python Python
results = await memory.query({
    "filter": {
        "memory": {"contains": "hiking"}
    }
})
```

```typescript TypeScript
const results = await memory.query({
  filter: {
    memory: { contains: 'hiking' }
  }
});
```
</CodeGroup>

### Date Range

Get memories from a specific time period:

<CodeGroup>
```python Python
from datetime import datetime

results = await memory.query({
    "filter": {
        "created_at": {
            "gte": datetime(2024, 1, 1),
            "lt": datetime(2024, 2, 1)
        }
    }
})
```

```typescript TypeScript
const results = await memory.query({
  filter: {
    createdAt: {
      gte: new Date('2024-01-01'),
      lt: new Date('2024-02-01')
    }
  }
});
```
</CodeGroup>

### Tags Filtering

<Tabs>
  <Tab title="Has ANY tag">
    ```python
    results = await memory.query({
        "filter": {
            "tags": {"any": ["work", "urgent"]}
        }
    })
    ```
    
    Matches memories with tags `["work"]`, `["urgent"]`, or `["work", "urgent", "other"]`
  </Tab>
  
  <Tab title="Has ALL tags">
    ```python
    results = await memory.query({
        "filter": {
            "tags": {"all": ["work", "project"]}
        }
    })
    ```
    
    Only matches memories that have BOTH "work" AND "project" tags
  </Tab>
</Tabs>

### Complex AND Logic

All conditions must match:

```python
results = await memory.query({
    "filter": {
        "user_id": "phone:123",
        "tags": {"any": ["work", "urgent"]},
        "created_at": {"gte": datetime(2024, 1, 1)},
        "memory": {"contains": "meeting"}
    }
})
```

This finds memories that match ALL of these:
- ✅ User ID is "phone:123"
- ✅ Has "work" OR "urgent" tag
- ✅ Created after Jan 1, 2024
- ✅ Contains the word "meeting"

### Complex OR Logic

Any condition can match:

```python
results = await memory.query({
    "filter": {
        "user_id": "phone:123",
        "OR": [
            {"tags": {"any": ["urgent"]}},
            {"memory": {"contains": "asap"}},
            {"memory": {"contains": "important"}}
        ]
    }
})
```

This finds memories where:
- ✅ User ID is "phone:123" (required)
- ✅ AND (has "urgent" tag OR contains "asap" OR contains "important")

### NOT Logic

Exclude certain results:

```python
results = await memory.query({
    "filter": {
        "user_id": "phone:123",
        "NOT": {
            "tags": {"any": ["archived", "deleted"]}
        }
    }
})
```

Finds memories for user EXCEPT those tagged as "archived" or "deleted"

### Metadata Filtering

Filter by custom metadata fields (JSONB):

```python
results = await memory.query({
    "filter": {
        "user_id": "phone:123",
        "metadata": {
            "priority": {"eq": "high"},
            "status": {"in": ["active", "pending"]},
            "score": {"gte": 80}
        }
    }
})
```

This filters memories where metadata contains:
- `priority` = "high"
- `status` is "active" OR "pending"
- `score` >= 80

## Nested Logic

Combine AND/OR/NOT for complex queries:

```python
results = await memory.query({
    "filter": {
        "user_id": "phone:123",
        "OR": [
            {
                # First possibility
                "tags": {"all": ["work", "urgent"]},
                "created_at": {"gte": datetime(2024, 1, 1)}
            },
            {
                # Second possibility
                "memory": {"search": "deadline project"},
                "metadata": {
                    "priority": {"eq": "high"}
                }
            }
        ],
        "NOT": {
            "tags": {"any": ["archived", "completed"]}
        }
    }
})
```

This translates to:
```
WHERE user_id = "phone:123"
  AND (
    (tags has ["work", "urgent"] AND created_at >= 2024-01-01)
    OR
    (memory contains "deadline" or "project" AND metadata.priority = "high")
  )
  AND NOT (tags has "archived" or "completed")
```

## Quick Filters

For common use cases, use these shortcuts instead of the full filter syntax:

```python
results = await memory.query({
    "search": "hiking mountains",  # Full-text search
    "tags_any": ["work", "urgent"],  # Has any of these tags
    "tags_all": ["work", "project"],  # Has all of these tags
    "after": datetime(2024, 1, 1),  # Created after
    "before": datetime(2024, 12, 31),  # Created before
    "pagination": {
        "limit": 50,
        "offset": 0
    }
})
```

## Sorting

Sort results by any field:

```python
results = await memory.query({
    "filter": {"user_id": "phone:123"},
    "sort": [
        {"field": "created_at", "order": "desc"},  # Newest first
        {"field": "score", "order": "asc"}  # Then by score ascending
    ]
})
```

## Pagination

### Offset-based Pagination

```python
# Page 1
page1 = await memory.query({
    "filter": {"user_id": "phone:123"},
    "pagination": {"limit": 20, "offset": 0}
})

# Page 2
page2 = await memory.query({
    "filter": {"user_id": "phone:123"},
    "pagination": {"limit": 20, "offset": 20}
})
```

### Cursor-based Pagination

```python
# First page
page1 = await memory.query({
    "filter": {"user_id": "phone:123"},
    "pagination": {"limit": 20}
})

# Next page using cursor
page2 = await memory.query({
    "filter": {"user_id": "phone:123"},
    "pagination": {
        "limit": 20,
        "cursor": page1.next_cursor
    }
})
```

## Full Example

Here's a comprehensive example showing all features:

```python
from datetime import datetime, timedelta

results = await memory.query({
    "filter": {
        # Required conditions
        "user_id": "phone:15103651277",
        
        # Complex OR logic
        "OR": [
            {
                # High priority work items
                "tags": {"all": ["work", "urgent"]},
                "metadata": {
                    "priority": {"eq": "high"},
                    "status": {"in": ["active", "in_progress"]}
                }
            },
            {
                # Recent personal memories
                "tags": {"any": ["personal", "family"]},
                "created_at": {
                    "gte": datetime.now() - timedelta(days=7)
                }
            }
        ],
        
        # Exclusions
        "NOT": {
            "tags": {"any": ["archived", "spam", "test"]},
            "memory": {"contains": "ignore this"}
        },
        
        # Text search
        "memory": {
            "search": "project deadline",
            "NOT": {"contains": "cancelled"}
        }
    },
    
    # Sorting
    "sort": [
        {"field": "metadata.priority", "order": "desc"},
        {"field": "created_at", "order": "desc"}
    ],
    
    # Pagination
    "pagination": {
        "limit": 50,
        "offset": 0
    },
    
    # Quick filters
    "after": datetime(2024, 1, 1),
    "tags_any": ["important"]
})

print(f"Found {len(results)} memories")
for memory in results:
    print(f"- {memory.memory}")
```

## Performance Tips

<AccordionGroup>
  <Accordion title="Use Indexes" icon="gauge-high">
    PhotoMem automatically creates indexes on:
    - `user_id`, `agent_id`, `run_id`
    - `created_at`, `updated_at`
    - `tags` (GIN index for array operations)
    - `custom_metadata` (GIN index for JSONB)
    
    For custom metadata fields you filter frequently, consider adding indexes:
    ```sql
    CREATE INDEX idx_metadata_priority 
    ON memories((custom_metadata->>'priority'));
    ```
  </Accordion>
  
  <Accordion title="Limit Results" icon="list">
    Always use `limit` to avoid fetching too many results:
    ```python
    results = await memory.query({
        "filter": {...},
        "pagination": {"limit": 100}  # Max 1000
    })
    ```
  </Accordion>
  
  <Accordion title="Use Full-Text Search" icon="magnifying-glass">
    The `search` operator uses PostgreSQL's tsvector which is much faster than `contains`:
    ```python
    # Fast - uses tsvector index
    "memory": {"search": "hiking mountains"}
    
    # Slower - requires full scan
    "memory": {"contains": "hiking mountains"}
    ```
  </Accordion>
  
  <Accordion title="Filter Early" icon="filter">
    Put the most selective filters first (user_id, date ranges) to reduce the result set early:
    ```python
    {
        "user_id": "phone:123",  # Very selective
        "created_at": {"gte": ...},  # Selective
        "tags": {"any": [...]},  # Less selective
        "memory": {"contains": ...}  # Least selective
    }
    ```
  </Accordion>
</AccordionGroup>
