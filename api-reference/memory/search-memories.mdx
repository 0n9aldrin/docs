title: 'Search Memories'

## Overview

Perform semantic search across memories using natural language queries. PhotoMem uses vector similarity to find the most relevant memories based on meaning, not just keyword matching.

<Info>
Search results are ranked by relevance score and can be filtered by user, agent, tags, and custom metadata.
</Info>

## Request Body

<ParamField body="query" type="string" required>
  Natural language search query. PhotoMem will find memories semantically similar to this query.
</ParamField>

<ParamField body="user_id" type="string">
  Filter results to memories associated with this user ID
</ParamField>

<ParamField body="agent_id" type="string">
  Filter results to memories associated with this agent ID
</ParamField>

<ParamField body="run_id" type="string">
  Filter results to memories from this specific conversation run
</ParamField>

<ParamField body="limit" type="integer" default="10">
  Maximum number of results to return. Range: 1-100
</ParamField>

<ParamField body="threshold" type="number" default="0.5">
  Minimum similarity score threshold (0-1). Only return results with scores above this value.
</ParamField>

<ParamField body="filters" type="object">
  Advanced filtering options.
  
  <Expandable title="Filter Options">
    <ParamField body="tags" type="array">
      Filter by specific tags
    </ParamField>
    
    <ParamField body="memory_type" type="string">
      Filter by memory type: `short_term` or `long_term`
    </ParamField>
    
    <ParamField body="date_range" type="object">
      Filter by date range with `start` and `end` ISO 8601 timestamps
    </ParamField>
  </Expandable>
</ParamField>

## Response

<ResponseField name="results" type="array">
  Array of matching memories ranked by relevance.
  
  <Expandable title="Result Object">
    <ResponseField name="id" type="string">
      Unique identifier for the memory
    </ResponseField>
    
    <ResponseField name="memory" type="string">
      The memory content
    </ResponseField>
    
    <ResponseField name="score" type="number">
      Similarity score (0-1). Higher scores indicate better matches.
    </ResponseField>
    
    <ResponseField name="rerank_score" type="number">
      Optional reranking score if reranking is enabled
    </ResponseField>
    
    <ResponseField name="hash" type="string">
      Content hash
    </ResponseField>
    
    <ResponseField name="metadata" type="object">
      Metadata including user_id, agent_id, tags, and timestamps
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="query" type="string">
  The original search query
</ResponseField>

<ResponseField name="count" type="integer">
  Number of results returned
</ResponseField>

<ResponseField name="total_matched" type="integer">
  Total number of memories that matched the query
</ResponseField>

<ResponseField name="search_time_ms" type="number">
  Time taken to perform the search in milliseconds
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST 'https://api.photomem.ai/v1/search' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "query": "What hobbies does the user have?",
    "user_id": "user_123",
    "limit": 5
  }'
```

```python Python
import requests

url = "https://api.photomem.ai/v1/search"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "query": "What hobbies does the user have?",
    "user_id": "user_123",
    "limit": 5
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
```

```javascript JavaScript
const response = await fetch('https://api.photomem.ai/v1/search', {

  },

    limit: 5
  })

const data = await response.json();
console.log(data);
```
