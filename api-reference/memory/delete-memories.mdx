## Overview

Bulk delete memories with optional filters. This endpoint allows you to delete multiple memories at once based on user_id, agent_id, or other criteria.

<Warning>
This is a destructive operation that permanently deletes multiple memories. Always use with caution and enable the `confirm` flag to prevent accidental deletions.
</Warning>

<Info>
Deleted memories are immediately removed and cannot be recovered. Consider exporting important memories before bulk deletion.
</Info>

## Query Parameters

<ParamField query="user_id" type="string">
  Filter deletion to memories belonging to a specific user. If omitted, will delete across all users (with confirm=true).
</ParamField>

<ParamField query="agent_id" type="string">
  Filter deletion to memories belonging to a specific agent.
</ParamField>

<ParamField query="confirm" type="boolean" required default="false">
  Safety flag that must be set to `true` to execute the deletion. This prevents accidental bulk deletions.
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE "https://api.photomem.ai/v1/memories?user_id=user_123&confirm=true" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import httpx

async def delete_memories(
    api_key: str,
    user_id: str = None,
    agent_id: str = None,
    confirm: bool = False
):
    async with httpx.AsyncClient() as client:
        params = {"confirm": str(confirm).lower()}
        if user_id:
            params["user_id"] = user_id
        if agent_id:
            params["agent_id"] = agent_id
        
        response = await client.delete(
            "https://api.photomem.ai/v1/memories",
            headers={"Authorization": f"Bearer {api_key}"},
            params=params,
        )
        response.raise_for_status()
        return response.json()

# Example usage:
# result = await delete_memories("YOUR_API_KEY", user_id="user_123", confirm=True)
```

```javascript TypeScript
async function deleteMemories(
  apiKey: string,
  options: {
    userId?: string;
    agentId?: string;
    confirm: boolean;
  }
): Promise<any> {
  const params = new URLSearchParams({
    confirm: options.confirm.toString(),
  });

  if (options.userId) {
    params.append("user_id", options.userId);
  }
  if (options.agentId) {
    params.append("agent_id", options.agentId);
  }

  const response = await fetch(
    `https://api.photomem.ai/v1/memories?${params}`,
    {
      method: "DELETE",
      headers: {
        Authorization: `Bearer ${apiKey}`,
      },
    }
  );

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  return response.json();
}

// Example usage:
// const result = await deleteMemories("YOUR_API_KEY", { userId: "user_123", confirm: true });
```
</RequestExample>

<Tip>
Always test your filters with [GET /v1/memories](/api-reference/memory/get-memories) first to see which memories will be deleted before running the bulk delete operation.
</Tip>

## Response

<ResponseField name="deleted" type="integer">
  Number of memories successfully deleted
</ResponseField>

<ResponseField name="message" type="string">
  Success message with deletion count
</ResponseField>

<ResponseExample>
```json 200
{
  "deleted": 42,
  "message": "Successfully deleted 42 memories"
}
```

```json 400
{
  "error": "Must set confirm=true for safety",
  "deleted": 0
}
```

```json 401
{
  "detail": "Invalid or missing API key."
}
```
</ResponseExample>

| Status | Meaning | Fix |
| --- | --- | --- |
| `200` | Success - memories deleted | — |
| `400` | Confirm flag not set to true | Add `confirm=true` query parameter |
| `401` | Authentication failed | Verify API key in Authorization header |

<Note>
If no filters are provided and confirm=true, this will delete ALL memories in your project. Always use at least one filter (user_id or agent_id) to limit scope.
</Note>
