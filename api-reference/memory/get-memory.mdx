## Overview

Retrieve a specific memory by its unique identifier. Use this endpoint when you have a memory ID and want to fetch its complete details.

<Info>
This endpoint returns the full memory object including all metadata, tags, and timestamps.
</Info>

## Path Parameters

<ParamField path="memory_id" type="string" required>
  Unique identifier of the memory to retrieve.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.photomem.ai/v1/memories/mem_abc123" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import httpx

async def get_memory(api_key: str, memory_id: str):
    async with httpx.AsyncClient() as client:
        response = await client.get(
            f"https://api.photomem.ai/v1/memories/{memory_id}",
            headers={"Authorization": f"Bearer {api_key}"},
        )
        response.raise_for_status()
        return response.json()

# Example usage:
# memory = await get_memory("YOUR_API_KEY", "mem_abc123")
```

```javascript TypeScript
async function getMemory(apiKey: string, memoryId: string): Promise<any> {
  const response = await fetch(
    `https://api.photomem.ai/v1/memories/${memoryId}`,
    {
      headers: {
        Authorization: `Bearer ${apiKey}`,
      },
    }
  );

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  return response.json();
}

// Example usage:
// const memory = await getMemory("YOUR_API_KEY", "mem_abc123");
```
</RequestExample>

## Response

<ResponseField name="id" type="string">
  Unique identifier for the memory
</ResponseField>

<ResponseField name="memory" type="string">
  The extracted memory text/fact
</ResponseField>

<ResponseField name="event" type="string">
  Event type - will be `"GET"` for this endpoint
</ResponseField>

<ResponseField name="hash" type="string">
  Content hash used for deduplication
</ResponseField>

<ResponseField name="metadata" type="object">
  <Expandable title="Metadata Fields">
    <ResponseField name="user_id" type="string">
      User ID associated with the memory
    </ResponseField>
    
    <ResponseField name="agent_id" type="string">
      Agent ID associated with the memory
    </ResponseField>
    
    <ResponseField name="run_id" type="string">
      Run/session ID associated with the memory
    </ResponseField>
    
    <ResponseField name="tags" type="array">
      Array of tags associated with the memory
    </ResponseField>
    
    <ResponseField name="custom" type="object">
      Custom metadata key-value pairs
    </ResponseField>
    
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp when memory was created
    </ResponseField>
    
    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp when memory was last updated
    </ResponseField>
  </Expandable>
</ResponseField>

| Status | Meaning | Fix |
| --- | --- | --- |
| `200` | Success - returns memory object | — |
| `404` | Memory not found | Verify the memory_id exists and is accessible with your API key |
| `401` | Authentication failed | Verify API key in Authorization header |

<Note>
Memory IDs are scoped to your organization. You can only retrieve memories that belong to your organization.
</Note>
