# POST /api/organizations/{orgId}/projects/{projectId}/api-keys

| Method | Path | Auth | Rate Limit |
| --- | --- | --- | --- |
| POST | `/api/organizations/{orgId}/projects/{projectId}/api-keys` | Bearer (Clerk JWT) | 20 req/min |

<Warning>
  API keys are only displayed once during creation. Store them securely - they cannot be retrieved later.
</Warning>

<Info>
  API keys authenticate requests to the PhotoMem API. Each key is scoped to a specific project and can be revoked independently.
</Info>

## Request

### Headers

| Name | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer CLERK_JWT_TOKEN` |
| `Content-Type` | Yes | `application/json` |

### Path Parameters

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `orgId` | string | Yes | Organization ID | `"org_abc123"` |
| `projectId` | string | Yes | Project ID | `"proj_xyz789"` |

### Body

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `name` | string | Yes | API key name for identification | `"Production Key"` |
| `permissions` | array | No | List of permissions (default: all) | `["read", "write"]` |
| `expires_at` | string | No | Expiration date (ISO 8601) | `"2024-12-31T23:59:59Z"` |

<CodeGroup>
```bash Shell
curl -X POST https://api.photomem.ai/api/organizations/org_abc123/projects/proj_xyz789/api-keys \
  -H "Authorization: Bearer $CLERK_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Production Key",
    "permissions": ["read", "write"]
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.photomem.ai/api/organizations/org_abc123/projects/proj_xyz789/api-keys",
    headers={
        "Authorization": f"Bearer {CLERK_JWT_TOKEN}",
        "Content-Type": "application/json"
    },
    json={
        "name": "Production Key",
        "permissions": ["read", "write"]
    }
)
response.raise_for_status()
data = response.json()

# IMPORTANT: Save this key - it won't be shown again!
print(f"API Key: {data['api_key']}")
```

```ts TypeScript
const response = await fetch(
  "https://api.photomem.ai/api/organizations/org_abc123/projects/proj_xyz789/api-keys",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${CLERK_JWT_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      name: "Production Key",
      permissions: ["read", "write"]
    }),
  }
);

const data = await response.json();

// IMPORTANT: Save this key - it won't be shown again!
console.log(`API Key: ${data.api_key}`);
```
</CodeGroup>

## Response

```json
{
  "api_key": "pm_live_AbCdEf123456_Xy9876ZaBcDeFg",
  "api_key_details": {
    "id": "key_123abc",
    "name": "Production Key",
    "key_prefix": "pm_live_AbCd",
    "permissions": ["read", "write"],
    "status": "active",
    "created_at": "2024-01-15T10:30:00Z",
    "expires_at": null,
    "last_used_at": null
  }
}
```

| Status | Meaning | Fix |
| --- | --- | --- |
| `201` | API key created successfully | — |
| `400` | Invalid request body | Check request format |
| `401` | Invalid or missing Clerk JWT | Verify JWT token from Clerk |
| `403` | Insufficient permissions | Requires MEMBER role or higher |
| `404` | Organization or project not found | Verify IDs |
| `429` | Rate limit exceeded | Slow down requests |

<Note>
  The `api_key` field contains the full key and is only returned once. The `key_prefix` can be used to identify the key later.
</Note>
