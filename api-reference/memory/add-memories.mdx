# POST /v1/memories

| Method | Path | Auth | Rate Limit |
| --- | --- | --- | --- |
| POST | `/v1/memories` | Bearer (API Key) | 100 req/min |

<Info>
  Use this endpoint to extract and store memories from conversation messages. PhotoMem automatically extracts relevant facts and creates searchable memories.
</Info>

## Request

### Headers

| Name | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer YOUR_API_KEY` |
| `Content-Type` | Yes | `application/json` |

### Body

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `messages` | array/string | Yes | Conversation messages or text to extract memories from | `[{"role": "user", "content": "I love pizza"}]` |
| `user_id` | string | Yes | Unique identifier for the user | `"user_123"` |
| `agent_id` | string | No | Identifier for the AI agent | `"agent_456"` |
| `run_id` | string | No | Session or run identifier | `"run_789"` |
| `metadata` | object | No | Additional metadata to attach | `{"source": "chat"}` |
| `tags` | array | No | Tags for categorization | `["support", "billing"]` |
| `memory_type` | string | No | Type of memory: `short_term` or `long_term` | `"long_term"` |
| `deduplicate` | boolean | No | Skip duplicate memories | `true` |

<CodeGroup>
```bash Shell
curl https://api.photomem.ai/v1/memories \
  -H "Authorization: Bearer $PHOTOMEM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {
        "role": "user",
        "content": "My name is Sarah and I work as a software engineer in San Francisco"
      }
    ],
    "user_id": "user_123"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.photomem.ai/v1/memories",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "messages": [
            {
                "role": "user",
                "content": "My name is Sarah and I work as a software engineer in San Francisco"
            }
        ],
        "user_id": "user_123"
    },
)
response.raise_for_status()
print(response.json())
```

```ts TypeScript
const response = await fetch("https://api.photomem.ai/v1/memories", {

const data = await response.json();
console.log(data);
```
</CodeGroup>

<Tip>
  PhotoMem automatically extracts multiple distinct facts from your messages. Each fact becomes a separate memory for better retrieval precision.
</Tip>

| Status | Meaning | Fix |
| --- | --- | --- |
| `201` | Memories stored successfully | — |
| `400` | Missing required field or invalid format | Provide valid `messages` and `user_id` |
| `401` | Invalid or missing API key | Check your API key in dashboard |
| `429` | Rate limit exceeded | Slow down requests or upgrade plan |

<Note>
  The `stats` object provides insights into memory extraction including duplicates detected and entities/relationships identified.
</Note>
