## LlamaIndex Integration

Enhance your LlamaIndex applications with PhotoMem's memory capabilities.

<Info>
This integration guide is coming soon! Check back for updates or [join our Discord](https://discord.gg/photomem) for early access.
</Info>

## Quick Example

```python
from llama_index.memory import PhotoMemMemory
from photomem import PhotoMem

# Initialize PhotoMem
client = PhotoMem(api_key="your-api-key")

# Use with LlamaIndex
memory = PhotoMemMemory(client=client)
```
