---
title: "List Webhooks"
api: "GET /api/organizations/{org_id}/projects/{project_id}/webhooks"
description: "List all webhooks for a project"
---

## Path Parameters

<ParamField path="org_id" type="string" required>
  Organization identifier
</ParamField>

<ParamField path="project_id" type="string" required>
  Project identifier
</ParamField>

## Response

<ResponseField name="webhooks" type="array">
  Array of webhook objects
  
  <Expandable title="Webhook">
    <ResponseField name="id" type="string">Webhook identifier</ResponseField>
    <ResponseField name="url" type="string">Webhook URL</ResponseField>
    <ResponseField name="events" type="array">
      Array of event types to trigger on
      
      **Available events:** `memory.created`, `memory.updated`, `memory.deleted`, `project.updated`
    </ResponseField>
    <ResponseField name="status" type="string">
      Status: `active` or `paused`
    </ResponseField>
    <ResponseField name="secret" type="string">Webhook signing secret</ResponseField>
    <ResponseField name="description" type="string">Optional description</ResponseField>
    <ResponseField name="createdAt" type="string">Creation timestamp</ResponseField>
    <ResponseField name="updatedAt" type="string">Last update timestamp</ResponseField>
    <ResponseField name="lastDeliveredAt" type="string">Last successful delivery (nullable)</ResponseField>
    <ResponseField name="statistics" type="object">
      Delivery statistics
      
      <Expandable title="Statistics">
        <ResponseField name="totalDeliveries" type="number">Total deliveries</ResponseField>
        <ResponseField name="successfulDeliveries" type="number">Successful deliveries</ResponseField>
        <ResponseField name="failedDeliveries" type="number">Failed deliveries</ResponseField>
        <ResponseField name="averageResponseTime" type="string">Average response time</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.photomem.io/api/organizations/{org_id}/projects/{project_id}/webhooks" \
  -H "Authorization: Bearer YOUR_CLERK_TOKEN"
```

```python Python
import requests

response = requests.get(
    f"https://api.photomem.io/api/organizations/{org_id}/projects/{project_id}/webhooks",
    headers={"Authorization": f"Bearer {clerk_token}"}
)

webhooks = response.json()["webhooks"]
for wh in webhooks:
    print(f"{wh['url']}: {wh['status']}")
```

```typescript TypeScript
const response = await fetch(
  `https://api.photomem.io/api/organizations/${orgId}/projects/${projectId}/webhooks`,
  {
    headers: {
      'Authorization': `Bearer ${clerkToken}`
    }
  }
);

const { webhooks } = await response.json();
webhooks.forEach(wh => console.log(`${wh.url}: ${wh.status}`));
```
