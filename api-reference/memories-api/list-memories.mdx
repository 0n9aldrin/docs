---
title: 'List Memories'
openapi: get /api/v1/memories
---

Retrieve a paginated list of memories for a project. Memories are returned in reverse chronological order (newest first).

## Authentication

This endpoint requires API Key authentication.

```bash
X-API-Key: pm_live_YOUR_API_KEY
```

## Path Parameters

<ParamField path="org_id" type="string" required>
  The unique identifier of the organization
</ParamField>

<ParamField path="project_id" type="string" required>
  The unique identifier of the project
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default={20}>
  Number of memories to return per page. Maximum: 100
</ParamField>

<ParamField query="offset" type="integer" default={0}>
  Number of memories to skip for pagination
</ParamField>

## Pagination Example

To retrieve all memories, use pagination:

```typescript
async function getAllMemories(orgId: string, projectId: string, apiKey: string) {
  const allMemories = [];
  let offset = 0;
  const limit = 100; // Use maximum for efficiency
  
  while (true) {
    const response = await fetch(
      `https://api.photomem.ai/api/organizations/${orgId}/projects/${projectId}/memories?limit=${limit}&offset=${offset}`,
      { headers: { 'X-API-Key': apiKey } }
    );
    
    const data = await response.json();
    allMemories.push(...data.memories);
    
    // Check if we've retrieved all memories
    if (offset + data.memories.length >= data.pagination.total) {
      break;
    }
    
    offset += limit;
  }
  
  return allMemories;
}
```

## When to Use List vs Search

<Tabs>
  <Tab title="Use List When">
    - You need to display all memories in chronological order
    - Building admin dashboards or analytics
    - Exporting data for backup or analysis
    - No specific query or filter needed
  </Tab>
  
  <Tab title="Use Search When">
    - Looking for specific information or topics
    - Need semantic similarity matching
    - Want to filter by user ID or tags
    - Implementing "memory-aware" AI responses
  </Tab>
</Tabs>
