---
title: "Get Usage Statistics"
api: "GET /api/organizations/{org_id}/usage"
description: "Get detailed usage statistics for an organization"
---

## Overview

Returns comprehensive usage statistics including API calls, storage metrics, costs, and usage limits for a specified time period.

## Authentication

Requires valid Clerk session token. User must be a member of the organization.

## Path Parameters

<ParamField path="org_id" type="string" required>
  Organization identifier
</ParamField>

## Query Parameters

<ParamField query="period" type="string" default="30d">
  Time period: `7d`, `30d`, `90d`, or `current_month`
</ParamField>

<ParamField query="projectId" type="string">
  Optional project ID to filter statistics
</ParamField>

<RequestExample>

```bash cURL
curl -X GET "https://api.photomem.io/api/organizations/{org_id}/usage?period=30d" \
  -H "Authorization: Bearer YOUR_CLERK_TOKEN"
```

```python Python
import requests

response = requests.get(
    f"https://api.photomem.io/api/organizations/{org_id}/usage",
    params={"period": "30d", "projectId": "proj_abc123"},
    headers={"Authorization": f"Bearer {clerk_token}"}
)

data = response.json()
usage = data["usage"]
limits = data["limits"]

print(f"API Calls: {usage['apiCalls']['total']:,} / {limits['apiCallsPerMonth']:,}")
print(f"Usage: {limits['percentUsed']['apiCalls']:.1f}%")
print(f"Total Cost: ${usage['costs']['total']:.2f}")
```

```javascript JavaScript
const response = await fetch(
  `https://api.photomem.io/api/organizations/${orgId}/usage?period=30d`,
  {
    headers: {'Authorization': `Bearer ${clerkToken}`}
  }
);

const data = await response.json();
console.log(`API Calls: ${data.usage.apiCalls.total.toLocaleString()}`);
console.log(`Cost: $${data.usage.costs.total.toFixed(2)}`);
```
