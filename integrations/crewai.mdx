## CrewAI Integration

Build powerful multi-agent systems with PhotoMem's shared memory capabilities.

<Info>
This integration guide is coming soon! Check back for updates or [join our Discord](https://discord.gg/photomem) for early access.
</Info>

## Quick Example

```python
from crewai import Agent, Task, Crew
from photomem import PhotoMem

# Initialize PhotoMem
memory = PhotoMem(api_key="your-api-key")

# Create agents with shared memory
agent = Agent(
    role="Assistant",
    memory=memory
)
```
