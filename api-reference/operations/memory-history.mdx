---
title: "Memory History"
api: "GET /v1/memories/{memory_id}/history"
description: "Get the change history of a specific memory"
---

## Path Parameters

<ParamField path="memory_id" type="string" required>
  The unique identifier of the memory
</ParamField>

## Response

<ResponseField name="results" type="array">
  Array of history entries, ordered by timestamp (newest first)
  
  <Expandable title="History Entry">
    <ResponseField name="id" type="string">
      History entry identifier
    </ResponseField>
    <ResponseField name="memory_id" type="string">
      Associated memory ID
    </ResponseField>
    <ResponseField name="old_memory" type="string">
      Previous content
    </ResponseField>
    <ResponseField name="new_memory" type="string">
      New content
    </ResponseField>
    <ResponseField name="event" type="string">
      Event type: `ADD`, `UPDATE`, or `DELETE`
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Timestamp of the change
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET https://api.photomem.ai/v1/memories/mem_abc123/history \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
history = await memory.history(memory_id="mem_abc123")
```

</RequestExample>
