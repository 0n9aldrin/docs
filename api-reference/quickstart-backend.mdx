# Backend API Quickstart

Get up and running with PhotoMem's backend APIs in minutes.

## Prerequisites

- A PhotoMem account ([Sign up here](https://app.photomem.io))
- Your organization and project set up
- An API key for your project

## Step 1: Authentication

First, create an API key for your project:

<Steps>
  <Step title="Log in to PhotoMem Dashboard">
    Visit [app.photomem.io](https://app.photomem.io) and log in with your account.
  </Step>
  
  <Step title="Navigate to your project">
    Go to **Organizations** → Select your org → **Projects** → Select your project.
  </Step>
  
  <Step title="Create an API Key">
    Click **API Keys** → **Create API Key**
    - Name: `My First Key`
    - Permissions: `read`, `write`
    - Expiration: 365 days
    
    Copy the key starting with `pm_live_...` - you'll only see it once!
  </Step>
</Steps>

## Step 2: Create Your First Memory

<CodeGroup>
```bash cURL
curl -X POST https://api.photomem.io/v1/memories \
  -H "X-API-Key: pm_live_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "user_alice",
    "userName": "Alice",
    "content": "Loves dark chocolate and prefers morning meetings",
    "tags": ["preference", "work"]
  }'
```

```javascript JavaScript
const response = await fetch('https://api.photomem.io/v1/memories', {
  method: 'POST',
  headers: {
    'X-API-Key': 'pm_live_YOUR_KEY_HERE',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    userId: 'user_alice',
    userName: 'Alice',
    content: 'Loves dark chocolate and prefers morning meetings',
    tags: ['preference', 'work']
  })
});

const memory = await response.json();
console.log('Created memory:', memory);
```

```python Python
import requests

response = requests.post(
    'https://api.photomem.io/v1/memories',
    headers={
        'X-API-Key': 'pm_live_YOUR_KEY_HERE',
        'Content-Type': 'application/json'
    },
    json={
        'userId': 'user_alice',
        'userName': 'Alice',
        'content': 'Loves dark chocolate and prefers morning meetings',
        'tags': ['preference', 'work']
    }
)

memory = response.json()
print('Created memory:', memory)
```
</CodeGroup>

**Response**:
```json
{
  "id": "mem_abc123",
  "userId": "user_alice",
  "userName": "Alice",
  "content": "Loves dark chocolate and prefers morning meetings",
  "tags": ["preference", "work"],
  "createdAt": "2024-01-20T15:30:00Z",
  "updatedAt": "2024-01-20T15:30:00Z"
}
```

## Step 3: Search Memories

Now search for memories about Alice:

<CodeGroup>
```bash cURL
curl -X POST https://api.photomem.io/v1/memories/search \
  -H "X-API-Key: pm_live_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What does Alice like?",
    "userId": "user_alice",
    "limit": 10
  }'
```

```javascript JavaScript
const response = await fetch('https://api.photomem.io/v1/memories/search', {
  method: 'POST',
  headers: {
    'X-API-Key': 'pm_live_YOUR_KEY_HERE',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    query: 'What does Alice like?',
    userId: 'user_alice',
    limit: 10
  })
});

const results = await response.json();
console.log('Found memories:', results);
```

```python Python
response = requests.post(
    'https://api.photomem.io/v1/memories/search',
    headers={
        'X-API-Key': 'pm_live_YOUR_KEY_HERE',
        'Content-Type': 'application/json'
    },
    json={
        'query': 'What does Alice like?',
        'userId': 'user_alice',
        'limit': 10
    }
)

results = response.json()
print('Found memories:', results)
```
</CodeGroup>

**Response**:
```json
{
  "results": [

      "id": "mem_abc123",
      "content": "Loves dark chocolate and prefers morning meetings",
      "userId": "user_alice",
      "userName": "Alice",
      "tags": ["preference", "work"],
      "relevance": 0.95,
      "createdAt": "2024-01-20T15:30:00Z"
    }
  ],
  "pagination": {
    "total": 1,
    "limit": 10,
    "offset": 0
  }
}
```

## Step 4: List Memories

Get all memories for a user:

```bash
curl -X GET "https://api.photomem.io/v1/memories?userId=user_alice&limit=20" \
  -H "X-API-Key: pm_live_YOUR_KEY_HERE"
```

## Step 5: Update a Memory

Update memory content or tags:

```bash
curl -X PATCH https://api.photomem.io/v1/memories/mem_abc123 \
  -H "X-API-Key: pm_live_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Loves dark chocolate, prefers morning meetings, and drinks coffee",
    "tags": ["preference", "work", "beverage"]
  }'
```

## Step 6: Delete a Memory

Remove a memory:

```bash
curl -X DELETE https://api.photomem.io/v1/memories/mem_abc123 \
  -H "X-API-Key: pm_live_YOUR_KEY_HERE"
```

## Error Handling

Always handle errors gracefully:

```javascript
try {
  const response = await fetch('https://api.photomem.io/v1/memories', {
    method: 'POST',
    headers: {
      'X-API-Key': apiKey,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(memoryData)
  });
  
  if (!response.ok) {
    const error = await response.json();
    console.error('API Error:', error.error.message);
    // Handle error appropriately
  }
  
  const memory = await response.json();
  return memory;
} catch (error) {
  console.error('Network error:', error);
  // Handle network error
}
```
