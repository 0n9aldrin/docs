---
title: "Export Usage Data"
api: "POST /api/organizations/{org_id}/usage/export"
description: "Request an export of usage data"
---

## Overview

Initiates an asynchronous export of usage data. Returns an export ID to check status and download the file when ready.

## Authentication

Requires valid Clerk session token. User must be a member of the organization.

## Path Parameters

<ParamField path="org_id" type="string" required>
  Organization identifier
</ParamField>

## Request Body

<ParamField body="startDate" type="string" required>
  Start date in ISO 8601 format
</ParamField>

<ParamField body="endDate" type="string" required>
  End date in ISO 8601 format
</ParamField>

<ParamField body="format" type="string" default="csv">
  Export format: `csv`, `json`, or `xlsx`
</ParamField>

<ParamField body="includeDetails" type="boolean" default={false}>
  Include detailed breakdown
</ParamField>

## Response

<ResponseField name="exportId" type="string">
  Unique export job identifier
</ResponseField>

<ResponseField name="status" type="string">
  Export status (initially "processing")
</ResponseField>

<ResponseField name="estimatedCompletionTime" type="string">
  ISO 8601 timestamp of estimated completion
</ResponseField>

<ResponseField name="downloadUrl" type="string">
  Download URL (null until completed)
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://api.photomem.io/api/organizations/{org_id}/usage/export" \
  -H "Authorization: Bearer YOUR_CLERK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "startDate": "2025-01-01T00:00:00Z",
    "endDate": "2025-01-31T23:59:59Z",
    "format": "csv",
    "includeDetails": true
  }'
```

```python Python
import requests
from datetime import datetime, timedelta

end_date = datetime.now()
start_date = end_date - timedelta(days=30)

response = requests.post(
    f"https://api.photomem.io/api/organizations/{org_id}/usage/export",
    headers={
        "Authorization": f"Bearer {clerk_token}",
        "Content-Type": "application/json"
    },
    json={
        "startDate": start_date.isoformat(),
        "endDate": end_date.isoformat(),
        "format": "csv",
        "includeDetails": True
    }
)

export_id = response.json()["exportId"]
print(f"Export started: {export_id}")
```

</RequestExample>

## Check Export Status

Use `GET /api/organizations/{org_id}/usage/export/{export_id}` to check the status.

```bash
curl -X GET "https://api.photomem.io/api/organizations/{org_id}/usage/export/exp_abc123xyz" \
  -H "Authorization: Bearer YOUR_CLERK_TOKEN"
```

Response when completed:

```json
{
  "exportId": "exp_abc123xyz",
  "status": "completed",
  "downloadUrl": "https://api.photomem.io/downloads/exp_abc123xyz.csv",
  "expiresAt": "2025-01-16T14:30:00Z",
  "fileSize": 1024000
}
```
