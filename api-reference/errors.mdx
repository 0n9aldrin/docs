## Overview

PhotoMem provides structured error handling with detailed error messages, error codes, and actionable suggestions. All errors extend a base `PhotoMemError` class with consistent properties across Python and TypeScript.

## Error Hierarchy

```
PhotoMemError (base)
├── ConfigurationError
├── ValidationError
├── MemoryNotFoundError
├── StorageError
├── LLMError
├── EmbeddingError
├── RateLimitError
└── NetworkError
```

## Error Classes

### PhotoMemError

Base class for all PhotoMem errors.

<Tabs>
  <Tab title="Python">
    ```python
    from photomem.exceptions import PhotoMemError

    try:
        # Some operation
        pass
    except PhotoMemError as e:
        print(f"Error Code: {e.error_code}")
        print(f"Message: {e.message}")
        print(f"Details: {e.details}")
        print(f"Suggestion: {e.suggestion}")
    ```

    **Properties:**
    - `error_code` (str): Error type identifier
    - `message` (str): Human-readable description
    - `details` (Dict[str, Any]): Additional context
    - `suggestion` (Optional[str]): How to fix
  </Tab>

  <Tab title="TypeScript">
    ```typescript
    import { PhotoMemError } from 'photomem';

    try {
      // Some operation
    } catch (error) {
      if (error instanceof PhotoMemError) {
        console.log(`Error Code: ${error.errorCode}`);
        console.log(`Message: ${error.message}`);
        console.log(`Details:`, error.details);
        console.log(`Suggestion: ${error.suggestion}`);
      }
    }
    ```

    **Properties:**
    - `errorCode` (string): Error type
    - `message` (string): Description
    - `details` (Record<string, any>): Context
    - `suggestion` (string | undefined): Fix
  </Tab>
</Tabs>

### ConfigurationError

Raised when there are configuration issues.

**Error Code:** `CONFIG_ERROR`

**Common Causes:**
- Missing API keys
- Invalid database URLs
- Incompatible settings

<Tabs>
  <Tab title="Python">
    ```python
    from photomem.exceptions import ConfigurationError

    try:
        memory = Memory(config)
    except ConfigurationError as e:
        print(f"Config issue: {e.message}")
        print(f"Fix: {e.suggestion}")
    ```
  </Tab>

  <Tab title="TypeScript">
    ```typescript
    import { ConfigurationError } from 'photomem';

    try {
      const memory = new Memory(config);
    } catch (error) {
      if (error instanceof ConfigurationError) {
        console.log(`Config issue: ${error.message}`);
        console.log(`Fix: ${error.suggestion}`);
      }
    }
    ```
  </Tab>
</Tabs>

**Example:**

```json
{
  "error_code": "CONFIG_ERROR",
  "message": "OpenAI API key not found",
  "details": {},
  "suggestion": "Set OPENAI_API_KEY environment variable or pass llmApiKey in config"
}
```

### ValidationError

Raised when input validation fails.

**Error Code:** `VALIDATION_ERROR`

**Common Causes:**
- Missing required fields
- Invalid data formats
- Type mismatches
- Out-of-range values

<Tabs>
  <Tab title="Python">
    ```python
    from photomem.exceptions import ValidationError

    try:
        result = await memory.add(
            messages="Hello",
            user_id=None  # Invalid: user_id required
        )
    except ValidationError as e:
        print(f"Validation failed: {e.message}")
        print(f"Field: {e.details.get('field')}")
        print(f"Fix: {e.suggestion}")
    ```
  </Tab>

  <Tab title="TypeScript">
    ```typescript
    import { ValidationError } from 'photomem';

    try {
      const result = await memory.add("Hello", {
        userId: null  // Invalid
      });
    } catch (error) {
      if (error instanceof ValidationError) {
        console.log(`Validation failed: ${error.message}`);
        console.log(`Field: ${error.details.field}`);
        console.log(`Fix: ${error.suggestion}`);
      }
    }
    ```
  </Tab>
</Tabs>

  "message": "user_id or agent_id must be provided",

}

### RateLimitError

Raised when API rate limits are exceeded.

**Error Code:** `RATE_LIMIT_ERROR`

**Common Causes:**
- Too many requests
- Quota exceeded
- Concurrent limit reached

<Tabs>
  <Tab title="Python">
    ```python
    from photomem.exceptions import RateLimitError
    import time

    try:
        result = await memory.add("text", user_id="phone:123")
    except RateLimitError as e:
        retry_after = e.details.get('retry_after_seconds', 60)
        print(f"Rate limited. Retry after {retry_after}s")
        time.sleep(retry_after)
        # Retry operation
    ```
  </Tab>

  <Tab title="TypeScript">
    ```typescript
    import { RateLimitError } from 'photomem';

    try {
      const result = await memory.add("text", { userId: "phone:123" });
    } catch (error) {
      if (error instanceof RateLimitError) {
        const retryAfter = error.details.retryAfterSeconds || 60;
        console.log(`Rate limited. Retry after ${retryAfter}s`);
        await new Promise(r => setTimeout(r, retryAfter * 1000));
        // Retry operation
      }
    }
    ```

## Error Handling Patterns

### Basic Try-Catch

<Tabs>
  <Tab title="Python">
    ```python
    from photomem import Memory
    from photomem.exceptions import PhotoMemError

    async def safe_add_memory(text: str, user_id: str):
        try:
            memory = Memory()
            await memory.initialize()
            result = await memory.add(text, user_id=user_id)
            return result
        except PhotoMemError as e:
            print(f"Error: {e.error_code} - {e.message}")
            return None
        finally:
            await memory.close()
    ```
  </Tab>

  <Tab title="TypeScript">
    ```typescript
    import { Memory, PhotoMemError } from 'photomem';

    async function safeAddMemory(text: string, userId: string) {
      const memory = new Memory();
      try {
        await memory.initialize();
        const result = await memory.add(text, { userId });
        return result;
      } catch (error) {
        if (error instanceof PhotoMemError) {
          console.log(`Error: ${error.errorCode} - ${error.message}`);
        }
        return null;
      } finally {
        await memory.close();
      }
    }
    ```
  </Tab>
</Tabs>

### Specific Error Handling

<Tabs>
  <Tab title="Python">
    ```python
    from photomem.exceptions import (
        ValidationError,
        MemoryNotFoundError,
        StorageError,
        RateLimitError
    )

    try:
        result = await memory.add(text, user_id=user_id)
    except ValidationError as e:
        # Handle invalid input
        print(f"Invalid input: {e.message}")
        return {"error": "validation", "message": e.message}
    except RateLimitError as e:
        # Handle rate limits with retry
        wait_time = e.details.get('retry_after_seconds', 60)
        print(f"Rate limited, waiting {wait_time}s...")
        await asyncio.sleep(wait_time)
        return await memory.add(text, user_id=user_id)
    except StorageError as e:
        # Handle storage failures
        print(f"Storage error: {e.message}")
        # Alert monitoring system
        alert_ops(e)
        return None
    except MemoryNotFoundError as e:
        # Handle missing memory
        print(f"Memory not found: {e.details['memory_id']}")
        return None
    ```
  </Tab>

  <Tab title="TypeScript">
    ```typescript
    import {
      ValidationError,
      MemoryNotFoundError,
      StorageError,
      RateLimitError
    } from 'photomem';

    try {
      const result = await memory.add(text, { userId });
    } catch (error) {
      if (error instanceof ValidationError) {
        // Handle invalid input
        console.log(`Invalid input: ${error.message}`);
        return { error: "validation", message: error.message };
      } else if (error instanceof RateLimitError) {
        // Handle rate limits
        const waitTime = error.details.retryAfterSeconds || 60;
        console.log(`Rate limited, waiting ${waitTime}s...`);
        await new Promise(r => setTimeout(r, waitTime * 1000));
        return await memory.add(text, { userId });
      } else if (error instanceof StorageError) {
        // Handle storage failures
        console.log(`Storage error: ${error.message}`);
        alertOps(error);
        return null;
      } else if (error instanceof MemoryNotFoundError) {
        // Handle missing memory
        console.log(`Not found: ${error.details.memoryId}`);
        return null;
      }
    }
    ```
  </Tab>

### Retry Logic

<Tabs>
  <Tab title="Python">
    ```python
    from photomem.exceptions import NetworkError, RateLimitError
    import asyncio

    async def add_with_retry(
        memory: Memory,
        text: str,
        user_id: str,
        max_retries: int = 3
    ):
        for attempt in range(max_retries):
            try:
                return await memory.add(text, user_id=user_id)
            except (NetworkError, RateLimitError) as e:
                if attempt == max_retries - 1:
                    raise  # Give up after max retries
                
                wait_time = 2 ** attempt  # Exponential backoff
                if isinstance(e, RateLimitError):
                    wait_time = e.details.get('retry_after_seconds', wait_time)
                
                print(f"Retry {attempt + 1}/{max_retries} after {wait_time}s")
                await asyncio.sleep(wait_time)
    ```
  </Tab>

  <Tab title="TypeScript">
    ```typescript
    import { NetworkError, RateLimitError } from 'photomem';

    async function addWithRetry(
      memory: Memory,
      text: string,
      userId: string,
      maxRetries: number = 3
    ) {
      for (let attempt = 0; attempt < maxRetries; attempt++) {
        try {
          return await memory.add(text, { userId });
        } catch (error) {
          if (error instanceof NetworkError || error instanceof RateLimitError) {
            if (attempt === maxRetries - 1) {
              throw error;  // Give up
            }
            
            let waitTime = Math.pow(2, attempt);  // Exponential backoff
            if (error instanceof RateLimitError) {
              waitTime = error.details.retryAfterSeconds || waitTime;
            }
            
            console.log(`Retry ${attempt + 1}/${maxRetries} after ${waitTime}s`);
            await new Promise(r => setTimeout(r, waitTime * 1000));
          } else {
            throw error;
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

## Error Response Format

All errors follow a consistent JSON structure:

```json
{
  "error_code": "VALIDATION_ERROR",
  "message": "Human-readable error description",
  "details": {
    "field": "user_id",
    "value": "invalid",
    "additional": "context"
  },
  "suggestion": "How to fix this error"
}
```

**Fields:**
- `error_code`: Machine-readable identifier
- `message`: Descriptive error message
- `details`: Context-specific information
- `suggestion`: Actionable fix recommendation

## Common Error Scenarios

### Missing API Keys

```python
# ❌ Error
ConfigurationError: OpenAI API key not found

# ✅ Fix
export OPENAI_API_KEY="sk-..."
# or
config = MemoryConfig(llm_api_key="sk-...")
```

### Invalid User ID Format

```python
# ❌ Error
ValidationError: ID must be in format 'type:value'

# ✅ Fix
user_id = "phone:15103651277"  # Not just "15103651277"
```

### Database Connection Failed

```python
# ❌ Error
StorageError: Failed to connect to PostgreSQL

# ✅ Fix
# Check if PostgreSQL is running
# Verify DATABASE_URL is correct
export DATABASE_URL="postgresql://user:pass@localhost:5432/photomem"
```

### Memory Not Found

```python
# ❌ Error
MemoryNotFoundError: Memory with ID 'xyz' not found

# ✅ Fix
# Verify the ID is correct
# Check if memory was deleted
# Confirm you're using the right database
```
