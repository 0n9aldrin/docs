## Overview

Permanently delete a specific memory by its unique identifier. This operation cannot be undone.

<Warning>
Deletion is permanent and cannot be reversed. Make sure you have the correct memory ID before calling this endpoint.
</Warning>

<Info>
Deleted memories are immediately removed from search results and cannot be retrieved. Consider implementing soft deletes in your application if you need to maintain history.
</Info>

## Path Parameters

<ParamField path="memory_id" type="string" required>
  Unique identifier of the memory to delete.
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE "https://api.photomem.ai/v1/memories/mem_abc123" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import httpx

async def delete_memory(api_key: str, memory_id: str):
    async with httpx.AsyncClient() as client:
        response = await client.delete(
            f"https://api.photomem.ai/v1/memories/{memory_id}",
            headers={"Authorization": f"Bearer {api_key}"},
        )
        response.raise_for_status()
        return response.status_code == 204

# Example usage:
# success = await delete_memory("YOUR_API_KEY", "mem_abc123")
```

```javascript TypeScript
async function deleteMemory(apiKey: string, memoryId: string): Promise<boolean> {
  const response = await fetch(
    `https://api.photomem.ai/v1/memories/${memoryId}`,
    {
      method: "DELETE",
      headers: {
        Authorization: `Bearer ${apiKey}`,
      },
    }
  );

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  return response.status === 204;
}

// Example usage:
// const success = await deleteMemory("YOUR_API_KEY", "mem_abc123");
```
</RequestExample>

<Tip>
For bulk deletions, consider using [DELETE /v1/memories](/api-reference/memory/delete-memories) with filters instead of calling this endpoint multiple times.
</Tip>

## Response

<ResponseField name="status" type="number">
  HTTP status code - `204` indicates successful deletion with no content returned.
</ResponseField>

<ResponseExample>
```json 204
No content returned on success
```

```json 404
{
  "detail": "Memory not found"
}
```

```json 401
{
  "detail": "Invalid or missing API key."
}
```

```json 403
{
  "detail": "You do not have permission to delete this memory."
}
```
</ResponseExample>

| Status | Meaning | Fix |
| --- | --- | --- |
| `204` | Success - memory deleted (no content) | — |
| `404` | Memory not found | Verify the memory_id exists and hasn't already been deleted |
| `401` | Authentication failed | Verify API key in Authorization header |
| `403` | Forbidden | Memory belongs to different organization or insufficient permissions |

<Note>
A `204 No Content` response indicates successful deletion. The response body will be empty.
</Note>
