# PATCH /v1/memories/{memory_id}

| Method | Path | Auth | Rate Limit |
| --- | --- | --- | --- |
| PATCH | `/v1/memories/{memory_id}` | Bearer (API Key) | 100 req/min |

<Info>
  Use this endpoint to update the content of an existing memory. This is useful for correcting information or refining stored facts.
</Info>

<Warning>
  Updating a memory regenerates its embedding vector, which may affect search results. Use carefully for significant content changes.
</Warning>

## Request

### Headers

| Name | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer YOUR_API_KEY` |
| `Content-Type` | Yes | `application/json` |

### Path Parameters

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `memory_id` | string | Yes | Unique identifier of the memory to update | `"mem_abc123"` |

### Body

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `data` | string | Yes | New content for the memory | `"User's full name is Sarah Johnson"` |

<CodeGroup>
```bash Shell
curl -X PATCH https://api.photomem.ai/v1/memories/mem_abc123 \
  -H "Authorization: Bearer $PHOTOMEM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "data": "User'\''s full name is Sarah Johnson"
  }'
```

```python Python
import requests

response = requests.patch(
    "https://api.photomem.ai/v1/memories/mem_abc123",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "data": "User's full name is Sarah Johnson"
    }
)
response.raise_for_status()
print(response.json())
```

```ts TypeScript
const response = await fetch(
  "https://api.photomem.ai/v1/memories/mem_abc123",
  {
    method: "PATCH",
    headers: {
      Authorization: `Bearer ${process.env.PHOTOMEM_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      data: "User's full name is Sarah Johnson"
    }),
  }
);

const data = await response.json();
console.log(data);
```
</CodeGroup>

## Response

```json
{
  "id": "mem_abc123",
  "memory": "User's full name is Sarah Johnson",
  "event": "UPDATE",
  "hash": "hash_new123",
  "metadata": {
    "user_id": "user_123",
    "agent_id": null,
    "run_id": null,
    "tags": ["personal"],
    "custom": {},
    "created_at": "2024-01-15T10:30:00Z",
    "updated_at": "2024-01-16T14:20:00Z"
  }
}
```

| Status | Meaning | Fix |
| --- | --- | --- |
| `200` | Memory updated successfully | — |
| `400` | Missing or invalid data field | Provide valid `data` string |
| `401` | Invalid or missing API key | Check your API key in dashboard |
| `404` | Memory not found | Verify memory_id exists |
| `429` | Rate limit exceeded | Slow down requests or upgrade plan |

<Note>
  The `updated_at` timestamp and `hash` will change when a memory is updated.
</Note>
