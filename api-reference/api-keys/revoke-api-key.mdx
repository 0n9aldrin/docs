---
title: "Revoke API Key"
api: "DELETE /api/organizations/{org_id}/projects/{project_id}/api-keys/{key_id}"
description: "Revoke an API key"
---

<Warning>
  This action is irreversible. Revoked keys cannot be reactivated. Create a new key if needed.
</Warning>

## Path Parameters

<ParamField path="org_id" type="string" required>
  The unique identifier of the organization
</ParamField>

<ParamField path="project_id" type="string" required>
  The unique identifier of the project
</ParamField>

<ParamField path="key_id" type="string" required>
  The unique identifier of the API key to revoke
</ParamField>

## Response

<ResponseField name="message" type="string">
  Confirmation message
</ResponseField>

<ResponseField name="revokedAt" type="string">
  ISO 8601 timestamp of when the key was revoked
</ResponseField>

<RequestExample>

```bash cURL
curl -X DELETE "https://api.photomem.io/api/organizations/{org_id}/projects/{project_id}/api-keys/{key_id}" \
  -H "Authorization: Bearer YOUR_CLERK_TOKEN"
```

```python Python
import requests

response = requests.delete(
    f"https://api.photomem.io/api/organizations/{org_id}/projects/{project_id}/api-keys/{key_id}",
    headers={"Authorization": f"Bearer {clerk_token}"}
)

result = response.json()
print(f"Key revoked at: {result['revokedAt']}")
```

```typescript TypeScript
const response = await fetch(
  `https://api.photomem.io/api/organizations/${orgId}/projects/${projectId}/api-keys/${keyId}`,
  {
    method: 'DELETE',
    headers: {
      'Authorization': `Bearer ${clerkToken}`
    }
  }
);

const result = await response.json();
console.log(`Key revoked at: ${result.revokedAt}`);
```
