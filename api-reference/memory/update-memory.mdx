## Overview

Update the content of an existing memory. This endpoint allows you to modify the text of a memory while preserving its ID and metadata.

<Info>
Updating a memory will regenerate its embeddings based on the new content and update the `updated_at` timestamp.
</Info>

<Warning>
Updates replace the entire memory text. The original content will be lost unless you maintain your own version history.
</Warning>

## Path Parameters

<ParamField path="memory_id" type="string" required>
  Unique identifier of the memory to update.
</ParamField>

## Request Body

<ParamField body="data" type="string" required>
  New content for the memory. This will replace the existing memory text.
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH "https://api.photomem.ai/v1/memories/mem_abc123" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "data": "User'\''s favorite color is dark blue."
  }'
```

```python Python
import httpx

async def update_memory(api_key: str, memory_id: str, new_content: str):
    async with httpx.AsyncClient() as client:
        response = await client.patch(
            f"https://api.photomem.ai/v1/memories/{memory_id}",
            headers={
                "Authorization": f"Bearer {api_key}",
                "Content-Type": "application/json",
            },
            json={"data": new_content},
        )
        response.raise_for_status()
        return response.json()

# Example usage:
# updated = await update_memory("YOUR_API_KEY", "mem_abc123", "User's favorite color is dark blue.")
```

```javascript TypeScript
async function updateMemory(
  apiKey: string,
  memoryId: string,
  newContent: string
): Promise<any> {
  const response = await fetch(
    `https://api.photomem.ai/v1/memories/${memoryId}`,
    {
      method: "PATCH",
      headers: {
        Authorization: `Bearer ${apiKey}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        data: newContent,
      }),
    }
  );

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  return response.json();
}

// Example usage:
// const updated = await updateMemory("YOUR_API_KEY", "mem_abc123", "User's favorite color is dark blue.");
```
</RequestExample>

<Tip>
Consider adding metadata to track why a memory was updated (e.g., `{"updated_reason": "user_correction"}`). You can update metadata separately if needed.
</Tip>

## Response

<ResponseField name="id" type="string">
  Unique identifier for the memory (unchanged)
</ResponseField>

<ResponseField name="memory" type="string">
  The updated memory text
</ResponseField>

<ResponseField name="event" type="string">
  Event type - will be `"UPDATE"` for this endpoint
</ResponseField>

<ResponseField name="hash" type="string">
  New content hash after update
</ResponseField>

<ResponseField name="metadata" type="object">
  <Expandable title="Metadata Fields">
    <ResponseField name="user_id" type="string">
      User ID associated with the memory
    </ResponseField>
    
    <ResponseField name="agent_id" type="string">
      Agent ID associated with the memory
    </ResponseField>
    
    <ResponseField name="run_id" type="string">
      Run/session ID associated with the memory
    </ResponseField>
    
    <ResponseField name="tags" type="array">
      Array of tags associated with the memory
    </ResponseField>
    
    <ResponseField name="custom" type="object">
      Custom metadata key-value pairs
    </ResponseField>
    
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp when memory was originally created (unchanged)
    </ResponseField>
    
    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp when memory was last updated (will be current time)
    </ResponseField>
  </Expandable>
</ResponseField>

| Status | Meaning | Fix |
| --- | --- | --- |
| `200` | Success - memory updated | — |
| `400` | Missing or invalid request body | Ensure `data` field is present and is a non-empty string |
| `404` | Memory not found | Verify the memory_id exists and is accessible |
| `401` | Authentication failed | Verify API key in Authorization header |

<Note>
The update operation is atomic. If the update fails, the original memory content remains unchanged.
</Note>
