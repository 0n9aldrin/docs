---
title: "Delete Memory"
api: "DELETE /v1/memories/{memory_id}/"
description: "Permanently delete a specific memory"
---

## Overview

Permanently delete a memory from your system. This action cannot be undone.

<Warning>
This operation is irreversible. Deleted memories cannot be recovered.
</Warning>

## Path Parameters

<ParamField path="memory_id" type="string" required>
  Unique identifier of the memory to delete
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates whether the deletion was successful
</ResponseField>

<ResponseField name="memory_id" type="string">
  ID of the deleted memory
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE 'https://api.photomem.ai/v1/memories/mem_abc123/' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

url = "https://api.photomem.ai/v1/memories/mem_abc123/"
headers = {
    "Authorization": "Bearer YOUR_API_KEY"
}

response = requests.delete(url, headers=headers)
print(response.json())
```

```javascript JavaScript
const response = await fetch('https://api.photomem.ai/v1/memories/mem_abc123/', {

    'Authorization': 'Bearer YOUR_API_KEY'

```
</RequestExample>

## Bulk Delete

To delete multiple memories at once, use the bulk delete endpoint:

```bash
POST /v1/memories/bulk-delete/
```

<CodeGroup>
```bash cURL
curl -X POST 'https://api.photomem.ai/v1/memories/bulk-delete/' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "memory_ids": ["mem_abc123", "mem_def456", "mem_ghi789"]
  }'
```

```python Python
import requests

url = "https://api.photomem.ai/v1/memories/bulk-delete/"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "memory_ids": ["mem_abc123", "mem_def456", "mem_ghi789"]
}

response = requests.post(url, json=data, headers=headers)
print(response.json())
```
</CodeGroup>

<Tip>
Use bulk delete when you need to remove multiple memories efficiently. It's faster than making individual delete requests.
</Tip>
